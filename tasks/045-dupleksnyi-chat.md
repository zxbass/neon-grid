# Миссия 045 — Дуплексный чат

> Уровень: `★★☆☆☆` · Тема: TCP-чат, duplex

Дуплексный чат между двумя точками Сетки. Джез нужно написать его с нуля: соединение, приём,
передача, и чтобы ни одно слово не потерялось в проводах.
— Разговор — это двусторонняя улица, — Зен поднимает два пальца. — Если одна сторона не слушает —
это уже не разговор, а монолог.
Джез открывает канал, и по нему впервые проходят живые слова.

---

## Часть 1 — Простой дуплекс

Клиент: подключается к серверу, читает stdin, шлёт строки; параллельно
читает с сокета и печатает. Сервер: принимает одно подключение,
эхом ретранслирует строки обратно (как в 042), но теперь без команды
`QUIT` — просто по `EOF`.

Проверка: клиент шлёт `привет` — видит `[echo] привет`.

### Выход

```bash
$ ./chat localhost 1200
> привет
[echo] привет
> ctrl-D
```

## Часть 2 — Разговорный сервер

Сервер теперь поддерживает **двух** клиентов и ретранслирует сообщения
от одного к другому. Имя клиента — первая строка после подключения.
Сообщения форматируются:

```text
[имя1] текст
```

Оба клиента обязаны видеть все сообщения в реальном времени. При
отключении одного — второму шлётся `[system] <имя> lost link`.

### Выход

```bash
$ ./chat-server 1200
$ ./chat 1200   (первый: ввёл "CROW")
$ ./chat 1200   (второй: ввёл "ZEN")
[CROW] ready
[ZEN] ready
[CROW] target locked
[ZEN] copy that
[system] CROW lost link
```

## Подсказки

- Клиенту нужны **два потока** (ввод + сокет) — или селектор/async.
- Не блокируй сервер на одном клиенте: принимай, затем в отдельном
  потоке читай и ретранслируй.
- Отправка должна идти сразу — не копи в буфер дольше, чем нужно.
