# Миссия 045 — Дуплексный чат

> Уровень: `★★☆☆☆` · Тема: TCP-чат, duplex

Дуплексный чат между двумя точками Сетки. Джез нужно написать его с нуля: соединение, приём,
передача, и чтобы ни одно слово не потерялось в проводах.
— Разговор — это двусторонняя улица, — Зен поднимает два пальца. — Если одна сторона не слушает —
это уже не разговор, а монолог.
Джез открывает канал, и по нему впервые проходят живые слова.

---

## Данные

`data/045/transcript.txt` — расшифровка чат-сессии. Строки вида
`[имя] текст` — сообщения участников, `[system] ...` — служебные
события сервера.

## Часть 1 — Сообщения

Прочитай `transcript.txt` и раздели строки на сообщения (`[имя] ...`) и
системные (`[system] ...`). Выведи:

- `MESSAGES` — сколько сообщений участников;
- `LAST` — последнее сообщение участника целиком.

### Выход

```text
MESSAGES: 4
LAST: [ZEN] copy that
```

## Часть 2 — Служебные строки

Выведи все системные строки в исходном порядке. Если их нет — ничего
не выводи.

### Выход

```text
[system] CROW lost link
```

## Подсказки

- Сообщение участника начинается с `[имя]`, системное — с `[system]`.
- Строки выводи без лишних переводов строк на конце.
- `LAST` — последняя **не-системная** строка, а не последняя в файле.
