# Миссия 117 — Симфония ботнета

> Уровень: `★★★★★` · Тема: координация ботнета, консенсус

Симфония ботнета: тысячи машин, которые играют по одной партитуре. Джез впервые управляет оркестром,
который не знает, что он оркестр.
— Оркестр звучит громче солиста, — Зен поднимает палец. — Но дирижёр у него один.
Джез становится дирижёром.

---

## Данные

- `data/117/nodes.txt` — ботнет: первая строка `N=<число узлов>`, далее
  `node <id> alive|dead` для каждого узла;
- `data/117/rounds.txt` — три раунда двухфазного коммита:
  `round <i> yes <x>` (x голосов «за» из N).

## Часть 1 — Выбор лидера

Лидер — **живой** узел с минимальным id. Подтверждение — число живых
узлов из N.

### Выход

```text
LEADER ELECTED: node 1 (confirmed by 7/10)
```

## Часть 2 — Двухфазный коммит

Для каждого раунда: если `x == N` (все узлы ответили YES) —
`COMMIT (started)`, иначе — `ABORT`.

### Выход

```text
ROUND 1: 9/10 YES -> ABORT
ROUND 2: 7/10 YES -> ABORT
ROUND 3: 10/10 YES -> COMMIT (started)
```

## Подсказки

- Если хоть один NO — ABORT, никто не стартует.
- Лидер знает общее число узлов (N).
