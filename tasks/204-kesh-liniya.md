# 204 — Кеш-линия

> Уровень: `★★★☆☆` · Тема: кеш-локальность · матрицы

CROW скидывает матрицу данных с датчиков и просит посчитать суммы. Джез пишет наивный код, и Дон
вздыхает: «Терминал будет жевать этот цикл, пока CROW не передумает платить».
— Память — это не склад, а конвейер, — Зен рисует на салфетке. — Одна линия — одна порция. Если
идти поперёк — каждый раз за новой порцией.
Джез учится ходить по линиям.

---

## Данные

- `data/204/matrix.bin` — матрица `128×128` значений `int32` в little-endian,
  строки идут подряд (row-major)

## Часть 1

Посчитай сумму всех элементов. Верни `SUM: <total>`.

## Часть 2

Посчитай суммы по каждому столбцу. Верни 128 строк `C<j>: <sum>` (нумерация
столбцов с 0).

Обрати внимание: если читать столбцы напрямую из row-major-раскладки, каждый
элемент — промах кеша. Ускоряй обход по строкам, накапливая суммы по столбцам.
