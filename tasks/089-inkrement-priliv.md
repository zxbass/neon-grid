# Миссия 089 — Инкремент «Прилив»

> Уровень: `★★★★☆` · Тема: инкрементальные бэкапы, дельта

Инкремент-прилив: резервные копии, которые копятся день за днём, и каждый слой — снимок чьей-то
жизни. Джез восстанавливает систему по слоям.
— Каждая копия — это слой времени, — Син смотрит на столбики бэкапов. — Сними лишнее — и время
поедет.
Джез аккуратно снимает слои.

---

## Часть 1 — Дельта-патч

Две версии файла (старая `old.bin`, новая `new.bin`). Вычисли дельту
в простом формате:

```text
<offset:u32 LE><len:u32 LE><новые байты>   — блок, который отличается
```

(блоки одинаковых байт между отличающимися — пропусти).

Примени патч к старой версии и получи новую. Проверь равенство
`apply(old, patch) == new`:

```text
PATCH: 3 blocks (offset=0 len=4, offset=16 len=2, offset=32 len=8)
ROUNDTRIP OK
```

## Часть 2 — Каскад бэкапов

Имеется бейзлайн `base.bin` и N версий: `v1.bin, v2.bin, ...`.
Построй инкрементальные патчи `p1..pN` (p1 — от base к v1, p2 — от
v1 к v2, ...). Затем восстанови `vN` из `base + p1 + p2 + ...` и сверь
с оригиналом:

```text
PATCHES: 5  TOTAL_BYTES: 2048 (base=4096)
RECONSTRUCT v5: OK (identical)
```

## Подсказки

- Поиск отличающихся блоков: сравнение побайтово, слияние соседних
  различий в один блок (если зазор < 4 байт — объединяй).
- Применение: копируй «старые» байты из старого файла + вставляй новые.
- Для больших файлов сравнивай блоками 4К, а не по байту.
