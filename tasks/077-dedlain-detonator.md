## Часть 1 — Тайм-аут операции

Функция `work(ms)`: спит `ms` и возвращает строку. Заверни её так,
чтобы при дедлайне `D` (мс) она возвращала `TIMEOUT`, если не успела.
Вход — пары `ms D`:

```
work 100 500  -> OK in 100ms
work 1000 500 -> TIMEOUT after 500ms
```

### Выход

```
100 500  -> OK
1000 500 -> TIMEOUT
```

## Часть 2 — Факторный взлом

Проверка кода от детонатора: попытка декодировать хэш методом грубой
силы — перебор PIN-ов с суммарным бюджетом времени. Известно:
проверка одного PIN занимает `t` мс, бюджет `B` мс. Перебирай PIN
(0,1,2,...), пока бюджет не исчерпан. Если взорвётся (PIN найден до
бюджета) — `UNLOCKED <pin>`; иначе `UNLOCKED` нет → `BOOM <last_pin>`.

Вход: `t B valid_pin`.

```
t=1 B=5000 valid=4242 -> UNLOCKED 4242 (перебрал 4243 за 4243ms)
t=1 B=1000 valid=9999 -> BOOM (дошли до 999 при 1000ms)
```

## Подсказки

- В Go — `context.WithTimeout`, в Python — `concurrent.futures.TimeoutError`
  / `threading.Timer`, в Rust — `tokio::time::timeout`.
- Проверяй, что таймаут реально останавливает работу (воркер-демон),
  а не просто «вернул ошибку».
- PIN — от 0, формат 4 цифры с лидирующими нулями.
