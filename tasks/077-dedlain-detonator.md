# Миссия 077 — Дедлайн «Детонатор»

> Уровень: `★★★☆☆` · Тема: тайм-ауты, дедлайны, контексты

Дедлайн-детонатор: таймауты, которые срабатывают, если ты не успел. Джез впервые учится говорить
«поздно» — себе, программам и тем, кто ждёт.
— Время — единственный ресурс, который нельзя докупить, — Дон ставит на стол часы. — Учись управлять
им, пока оно управляет тобой.
Джез учится успевать. Или хотя бы вовремя останавливаться.

---

## Данные

- `data/077/pairs.txt` — пары `время_работы_мс дедлайн_мс`;
- `data/077/budget.txt` — тройки `t_мс бюджет_мс верный_PIN`.

## Часть 1 — Тайм-аут операции

Работа занимает `время_работы` мс; если оно больше дедлайна — `TIMEOUT`,
иначе — `OK`:

```text
100 500  -> OK
1000 500 -> TIMEOUT
250 300  -> OK
```

## Часть 2 — Факторный взлом

Перебор PIN 0000..9999: проверка одного PIN занимает `t` мс. PIN-ы
проверяются по порядку, пока не кончится бюджет. Если верный PIN попал
в перебор (проверок × t ≤ бюджет) — `UNLOCKED <pin>`, иначе —
`BOOM <последний_проверенный>`. Формат — 4 цифры с ведущими нулями:

```text
UNLOCKED 4242
BOOM 0999
BOOM 1499
```

## Подсказки

- В Go — `context.WithTimeout`, в Python — `concurrent.futures`.
- Таймаут должен реально останавливать работу, а не «вернуть ошибку».
- Последний проверенный PIN — тот, чья проверка съела последний
  миллисекунду бюджета.
