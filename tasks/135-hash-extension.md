# 135 — Hash length extension

> Уровень: `★★★★☆` · Тема: hash length extension · атаки

Сервер «Гаража» принимает MAC от ключа, которого ни у кого нет. Но Джез замечает: хеш можно
продолжать, как разговор, начатый без неё.
— Иногда не нужно знать начало, — Зен поправляет очки. — Достаточно продолжить.
Джез продолжает чужой разговор.

## Данные

- `data/135/input.txt` — `KEYLEN`, `MESSAGE`, `MAC`

## Часть 1

Верни `FORGED_MAC: <hex>` — поддельный MAC для сообщения с суффиксом `&admin=1`.

## Часть 2

Верни `FORGED_MAC2: <hex>` и `PAYLOAD: <hex>` для суффикса `&role=zen` — payload = весь подделанный
байт-поток `message || padding || suffix`.
