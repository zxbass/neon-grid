# Миссия 070 — Панель взлома

> Уровень: `★★★★☆` · Тема: TUI, шифры, анимация, время реакции

Панель взлома, собранная вручную: окна, статусы, кнопки. Джез собирает свой командный пункт и
впервые чувствует, что у неё есть инструмент, а не только чужие программы.
— Хороший инструмент — продолжение рук, — Дон ставит перед ней клавиатуру. — Сделай его удобным, и
руки тебе скажут спасибо.
Джез делает инструмент, и руки говорят спасибо.

## Часть 1 — Случайный код

Панель показывает 6-значный код, зашифрованный XOR с ключом `0x5A`,
по одному числу на строку. Игрок вводит дешифрованный код.

Вход — файл с зашифрованными кодами (hex). Для каждого выведи
расшифрованный и результат сверки с введённым (для теста возьми код
из файла-ответа):

```text
CODE: 4A 0C 33 4C 0A 2B  -> DECRYPTED: 16 86 105 22 80 113
CHECK: 16 86 105 22 80 113 -> MATCH
```

## Часть 2 — Гонка с трекером

Игровой цикл: код показывается на 3 секунды (анимация «дождь» из
066 вокруг), потом прячется. Игрок вводит. Трекер ползёт снизу
вверх; если дошёл до верха до ввода — `TRACED`.

Тест без клавиатуры: код вводится из файла построчно. Условия:
успеваешь за 3 с → `ACCESS GRANTED`; иначе `TRACED` (тогда вывести
следы для следующего раунда).

Выведи итог серии из 5 раундов:

```text
ROUNDS: 3/5 passed
FINAL: ACCESS GRANTED
```

## Подсказки

- Таймер: засекай время чтения из файла или тик каждые 100 мс.
- «Дождь» — декорация: случайные символы в колонках вокруг рамки.
- Порядок вывода: раунд → статус → финал. Всё в терминал/файл.
