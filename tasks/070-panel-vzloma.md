# Миссия 070 — Панель взлома

> Уровень: `★★★★☆` · Тема: TUI, шифры, раунды, время реакции

Панель взлома, собранная вручную: окна, статусы, кнопки. Джез собирает свой командный пункт и
впервые чувствует, что у неё есть инструмент, а не только чужие программы.
— Хороший инструмент — продолжение рук, — Дон ставит перед ней клавиатуру. — Сделай его удобным, и
руки тебе скажут спасибо.
Джез делает инструмент, и руки говорят спасибо.

---

## Данные

- `data/070/codes.txt` — зашифрованные коды, по одному на строку:
  шесть байт в hex (`4A 0C 33 4C 0A 2B`);
- `data/070/answers.txt` — введённые игроком ответы, по одному на
  строку: шесть десятичных чисел;
- `data/070/rounds.txt` — раунды: `КОД|ОТВЕТ|ТИКИ` (по одному на
  строку).

## Часть 1 — Случайный код

Панель показывает 6-значный код, зашифрованный XOR с ключом `0x5A`.
Расшифруй каждый код из `codes.txt` (каждый байт — `байт XOR 0x5A`)
и сверь с ответом из `answers.txt`. Выведи для каждого кода две строки:

```text
CODE: 4A 0C 33 4C 0A 2B -> DECRYPTED: 16 86 105 22 80 113
CHECK: 16 86 105 22 80 113 -> MATCH
```

### Выход

```text
CODE: 4A 0C 33 4C 0A 2B -> DECRYPTED: 16 86 105 22 80 113
CHECK: 16 86 105 22 80 113 -> MATCH
CODE: 70 5D 92 A5 5B 00 -> DECRYPTED: 42 7 200 255 1 90
CHECK: 42 7 200 255 1 90 -> MATCH
CODE: 5A 5B 58 59 5E 5F -> DECRYPTED: 0 1 2 3 4 5
CHECK: 0 1 2 99 4 5 -> FAIL
```

## Часть 2 — Гонка с трекером

Игровой цикл: код показывается, игрок вводит ответ, трекер ползёт
вверх. Раунд проходит, если ответ совпал **и** тиков не больше 30.
Для каждого раунда из `rounds.txt` выведи:

- ответ совпал и `тики <= 30` — `ROUND N: ACCESS GRANTED`;
- тиков больше 30 — `ROUND N: TRACED (N тиков)`;
- ответ не совпал — `ROUND N: TRACED (wrong code)`.

В конце — сводку: `ROUNDS: X/5 passed` и `FINAL: ACCESS GRANTED`,
если прошло не меньше половины раундов (`X*2 >= 5`), иначе
`FINAL: TRACED`.

### Выход

```text
ROUND 1: ACCESS GRANTED
ROUND 2: TRACED (31 ticks)
ROUND 3: ACCESS GRANTED
ROUND 4: ACCESS GRANTED
ROUND 5: TRACED (wrong code)
ROUNDS: 3/5 passed
FINAL: ACCESS GRANTED
```

## Подсказки

- Таймер симулируется файлом: «тики» — поле в `rounds.txt`, никаких
  замеров времени.
- Ответы в `answers.txt` и `rounds.txt` — это ввод игрока: он может
  содержать опечатки (FAIL / wrong code).
- Шестнадцатеричный ввод: `strconv.ParseUint(hex, 16, 8)`.
