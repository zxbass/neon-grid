# Миссия 068 — Браузер-терминал

> Уровень: `★★★☆☆` · Тема: TUI-браузер, навигация

Браузер терминала: страница — это текст, ссылка — это путь. Джез строит собственный способ ходить по
документам и впервые видит Сеть как библиотеку.
— Сеть — это книга, — CROW стучит пальцем по столу. — Только страницы в ней пишут сами себя.
Джез листает страницы, которые пишут себя сами.

---

## Данные

- `data/068/index.html`, `about.html`, `login.html`, `flag.html` —
  страницы сайта (HTML, ссылки `<a href="...">`);
- `data/068/commands.txt` — команды навигации, по одной на строку.

Карта ссылок:

- `index.html`: `[0] about.html` «About us», `[1] login.html`
  «Employee login», `[2] flag.html` «Restricted»;
- `about.html` и `login.html`: `[0] index.html` «Home»,
  `[1] flag.html` «The Gate»;
- `flag.html` — ссылок нет.

## Часть 1 — Загрузка и текст

Прочитай `index.html`, вытащи `<title>` и текстовое содержимое
`<body>`: убери теги `<a>...</a>` целиком, затем все остальные теги,
схлопни пробельные символы (включая переводы строк) в одиночные
пробелы и обрежь края.

```text
TITLE: OMEGA-DYNE // Corporate Hub
BODY: Welcome, citizen. Trust us.
```

## Часть 2 — Навигация

Начни с `index.html`. Для каждой команды из `commands.txt`:

- `<число>` — перейти по ссылке с этим номером на текущей странице
  (номер вне диапазона — команда игнорируется); текущая страница
  кладётся в историю;
- `back` — вернуться на предыдущую страницу из истории;
- `quit` — остановиться (сама команда не выводится).

Для каждой команды, кроме `quit`, выведи `> <команда>`. В конце выведи
`TITLE:` и `BODY:` финальной страницы:

### Выход

```text
> 1
> 0
> back
> 1
TITLE: FLAG PAGE
BODY: FLAG{TUI_SURFING_IS_PURE}
```

## Подсказки

- Храни стек истории для `back`.
- Ссылки нумеруй в порядке появления в HTML.
- `BODY` считается как в Части 1 (ссылки исключаются).
