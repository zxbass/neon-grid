# Миссия 100 — Волна интерфейса

> Уровень: `★★★★★` · Тема: сжатие волн, прогнозирование, нейроинтерфейс

Волна интерфейса: сигнал, который рисует график — и в графике слышен ритм. Джез впервые видит звук глазами и слышит картинку ушами.
— Всё — волны, — Син касается экрана. — Только одни мы слышим, а другие видим.
Джез учится видеть и слышать одновременно.

---

## Часть 1 — DPCM-предсказание

Семплы — 16-бит signed. Кодер DPCM:

- `pred = previous sample` (или предыдущая дельта);
- ошибка `e = sample - pred`;
- квантуй `e` до 4 бит (шаг 32: `q = e / 32`, в диапазоне -8..7);
- восстановленное значение `rec = pred + q*32`;
- следующий `pred = rec`.

Закодируй файл `wave.bin` в поток квантизаций (по 2 на байт) и
посчитай среднюю абсолютную ошибку между оригиналом и восстановленной
волной:

```
CODEC: 4-bit DPCM  avg_err=12.3  ratio=4.0x
```

## Часть 2 — Адаптивный шаг

Улучши: шаг квантования адаптивный. Если подряд идут большие ошибки —
шаг растёт (×1.5), если ошибки малые — шаг падает (÷1.2). Ограничь
шаг 4..256.

Цель: при том же 4-битном коде средняя ошибка не больше 60% от части 1.
Сравни:

```
DPCM:  avg_err=12.3
ADAPT: avg_err=7.1  (better by 42%)
```

## Подсказки

- Декодер: `sample = pred + q*step` — кодер и декодер считают `pred`
  одинаково.
- Адаптация шага — только по квантованной ошибке (обе стороны видят
  одно и то же!).
- Формат выходного потока: 1 байт — начальный шаг, затем нибблы.
