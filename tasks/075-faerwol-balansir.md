# Миссия 075 — Фаервол-балансир

> Уровень: `★★★★☆` · Тема: load balancer, health check

Фаервол-балансир: весь трафик квартала через один распределитель, и никто не должен ждать дольше
соседа. Дон доверяет Джез сеть, по которой ходят деньги.
— Балансир — это весы, — он говорит серьёзно. — Перевесь в одну сторону — и кто-то останется
голодным.
Джез держит весы ровно.

---

## Данные

- `data/075/rr.log` — журнал соединений: `HH:MM:SS имя бэкенд`;
- `data/075/health.log` — журнал health-чеков: `t=мс бэкенд UP|DOWN`
  (состояние действует до следующего чека);
- `data/075/conns.txt` — моменты подключений клиентов (мс), по одному
  числу на строку.

## Часть 1 — Round Robin

Посчитай по `rr.log`, сколько соединений ушло на каждый бэкенд (в
порядке первого упоминания):

```text
BACKENDS: 1200:3 1201:3 1202:3
```

## Часть 2 — Health check

Симулируй распределение: бэкенды 1200, 1201, 1202 обходятся по кругу,
но только среди живых (состояние на момент подключения по
`health.log`). Указатель круга переходит только по живым бэкендам.
Выведи распределение 9 клиентов:

```text
DISTRIBUTION: 1200:4 1201:2 1202:3
```

## Подсказки

- Отдельный поток для health-чека; список живых — под мьютексом.
- RR-индекс растёт только по живым бэкендам.
- Если все бэкенды DOWN — клиент получает `503 NO_BACKENDS`.
