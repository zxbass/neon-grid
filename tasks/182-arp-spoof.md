# 182 — ARP-спуфинг

> Уровень: `★★★★☆` · Тема: ARP · спуфинг

ARP-спуфинг: сказать сети «этот адрес — мой», и сеть поверит. Джез учится тому, что в Сетке доверие
выдают по запросу.
— Память сети коротка, — Прах смотрит на кэш. — А ложь — вечна.
Джез отравляет память сети.

---

## Данные

- `data/182/arp.txt` — перехваченный запрос и честный ответ

## Часть 1

Собери поддельный ARP-reply (Ethernet + ARP): dst = MAC жертвы, src = твой MAC, op = 2, sender =
твой MAC + IP 10.0.0.1, target = MAC жертвы + её IP 10.0.0.2. Верни `SPOOFED_REPLY: <hex>`.

Твой MAC: `AA:BB:CC:DD:EE:FF`, MAC жертвы: `00:11:22:33:44:55`.

## Часть 2

Верни `CACHE POISONED: 10.0.0.1 -> AA:BB:CC:DD:EE:FF`.
