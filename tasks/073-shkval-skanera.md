# Миссия 073 — Шквал сканера

> Уровень: `★★★☆☆` · Тема: async-сканер, тайм-ауты

Шквал сканера: тысячи адресов, один проход. Джез учится запускать много дел одновременно и не
захлёбываться потоком ответов.
— Параллельность — это веер, — Зен раскрывает ладонь. — Раскрой — и накроешь весь квартал.
Джез раскрывает веер и накрывает квартал.

---

## Данные

`data/073/scan.txt` — детерминированный результат скана. Параметры:

- `range начало конец` — диапазон портов (всего N портов);
- `concurrency C` — глубина параллельности (волна);
- `pulse мс` — пауза между стартами попыток (rate limit);
- `delay мс` — время одной проверки порта;
- `порт OPEN|FILTERED|CLOSED` — результат проверки порта.

## Часть 1 — Семафор

Сканирование идёт волнами по `C` портов; волна занимает `delay` мс,
волн — `⌈N/C⌉`. Выведи открытые порты и общее время:

```text
OPEN: 22 80 1200 8080  C=50: 1024 ports in 4200ms
```

## Часть 2 — Ограничение скорости

Попытки стартуют не чаще раза в `pulse` мс: первая — сразу, остальные
ждут (очередь). Ждавших — `N − 1`; время скана —
`(N−1) × pulse + delay`. Скорость — `1000 / pulse` попыток/сек.
Выведи число открытых портов и сводку:

```text
OPEN: 4  RATE: 250/s  QUEUED: 1023  TIME: 4292ms
```

## Подсказки

- Семафор = канал с буфером `C`: берёшь токен до проверки, отдаёшь
  после.
- В «очередь» попадают попытки, стартовавшие бы раньше, чем позволено.
- FILTERED порты в списке открытых не появляются.
