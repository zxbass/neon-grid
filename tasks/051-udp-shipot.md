# Миссия 051 — UDP-шёпот

> Уровень: `★★★☆☆` · Тема: UDP, дейтаграммы

UDP — шёпот в Сетке: послал и не ждёшь ответа. На нижних уровнях так шепчутся те, кому нечего
прятать, и те, кому прятать нечего не хватает.
— Доверие — это когда тебе не нужен ответ, — Син говорит это тихо, глядя в окно. — Но за шёпотом
тоже кто-то стоит.
Джез учится слышать шёпот и различать в нём голоса.

---

## Часть 1 — Эхо по UDP

UDP-сервер на порту 1201: принимает дейтаграммы (до 1024 байт),
отвечает **тем же** содержимым обратно на адрес отправителя. Клиент
шлёт строку и ждёт ответ (тайм-аут 2 с).

### Выход

```bash
$ ./udp-echo 1201
$ ./udp-ping 1201 "CROW HERE"
CROW HERE
```

## Часть 2 — Шифрованный шёпот

Поток стал секретным: каждое сообщение — дейтаграмма `[0x7E][1 байт
seq][данные XOR-key][1 байт чексумма]`, где чексумма — XOR всех байт
`seq` и данных (до шифрования), а `key` — общий байт (0x4D).

Клиент отправляет: seq увеличивается с 0, данные — текст XOR `key`.
Сервер расшифровывает, проверяет чексумму и seq (не больше чем на 1
от последнего, иначе `REORDER`) и отвечает `ACK <seq>` или `BAD`.

### Выход

```bash
$ ./udp-secret 1201 "the grid is listening"
ACK 0
ACK 1
...
```

## Подсказки

- UDP в Go — `net.ListenUDP`/`ReadFromUDP`; Python — `socket.SOCK_DGRAM`.
- Дейтаграмма = целое сообщение; не нужно буферизовать «поток».
- XOR данных с ключом до чексуммы — порядок важен, он в условии.
