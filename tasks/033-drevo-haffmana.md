# Миссия 033 — Древо Хаффмана

> Уровень: `★★★★☆` · Тема: код Хаффмана, битовые потоки

Дерево Хаффмана — способ записать частые буквы коротко, а редкие — длинно. На нижнем уровне так устроены все тарифы: кто говорит часто — платит мало, кто молчит — дорого.
— Сжатие — это уважение к чужому времени, — говорит Зен. — И к своему тоже.
Джез строит дерево из частот и с удивлением понимает, что оно растёт само.

---

## Часть 1 — Построение древа

По частотам символов построй бинарное дерево Хаффмана (минимальная
куча по частоте; при равных частотах — меньший символ первым).
Выведи для каждого символа его код (битовая строка, путь `0`/`1`
от корня):

```
'a': 0
'b': 10
'c': 110
'd': 111
```

### Вход

```
freqs: a=45 b=13 c=12 d=16 e=9 f=5
```

(это классика: ожидай `a:0 b:101 c:100 d:111 e:1101 f:1100` —
зависит от твоего порядка слияний; главное — префиксность.)

## Часть 2 — Канонический декодер

Перехваченный файл содержит: 4 байта — число символов `N` (u32 BE),
затем для каждого из `N` символов: байт символа, байт длины кода.
После таблицы — битовый поток кодов (биты идут MSB-first), дополненный
нулями до байта.

Собери канонические коды (сортировка по длине, затем по значению
символа; коды идут последовательно), распакуй поток и выведи текст.

### Выход

```
DECODED: <текст>
```

## Подсказки

- Канонические коды: отсортируй пары `(len, symbol)`, первый код —
  `0` длины `len[0]`, каждый следующий = предыдущий `+1` с приращением
  длины.
- Для декодирования бери биты по одному, иди по древу (или хеш-таблице
  код→символ с жадным префиксом).
- Число бит в потоке может быть меньше 8×len — следи, чтобы не выйти
  за реальные данные.
