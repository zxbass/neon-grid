# Миссия 087 — RAID-воскрешение

> Уровень: `★★★★☆` · Тема: RAID, XOR-паритет

RAID-воскресение: данные размазаны по дискам, и чтобы прочитать их, нужно собрать пазл. Джез восстанавливает массив, потерявший диск, и учится тому, что потеря — не всегда конец.
— RAID — это про «на всякий случай», — Дон кивает на стойку дисков. — И «на всякий случай» иногда спасает.
Джез собирает пазл и возвращает данные к жизни.

---

## Часть 1 — RAID5-восстановление

RAID5 с 4 дисками (3 данных + 1 паритет), страйп 4 КБ, паритет
ротируется: на страйпе `s` паритет на диске `s % 4`. Паритет —
XOR всех дисков страйпа (без паритетного).

Даны образы `disk0..disk3.bin`, один из дисков заполнен нулями
(«умер»). Восстанови его: `dead = XOR всех живых` по страйпам.

Выведи: какой диск умер и что его первый байт после восстановления:

```
DEAD: disk2
RESTORED: disk2[0]=0x4D
```

## Часть 2 — Извлечение файла

На восстановленном диске (или наборе всех четырёх) находится файл
`RAID.TXT` (несколько страйпов). Собери его из страйпов: страйп
`i` на наборе дисков — это байты с дисков в порядке 0,1,2,3,
пропуская паритетный диск страйпа. Выведи содержимое:

```
RAID.TXT: THE_PURGE_BEGINS_AT_DUSK
```

## Подсказки

- Размер страйпа в байтах — 4096; страйп-группа = 4 × 4096.
- Восстановление: для каждого страйпа XOR живых, сравнение с нулями
  не нужно — если диск нулевой на всех страйпах, это «мёртвый».
- Сборка файла: блочный дедупликатор порядка; файл может быть короче
  страйпа — по длине заголовка.
- Проверяй себя: `dead_disk == xor(other_three)` для каждого страйпа.
