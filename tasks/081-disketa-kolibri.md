Образ `floppy.img`, 1.44 МБ, сектора по 512 байт. BPB (смещения):

| Смещение | Поле |
| ---------- | ------ |
| 11 | bytes/sector (u16 LE) |
| 13 | sectors/cluster (u8) |
| 14 | reserved sectors (u16 LE) |
| 16 | число FAT (u8) |
| 17 | корневых записей (u16 LE) |
| 19 | всего секторов (u16 LE) |
| 22 | sectors per FAT (u16 LE) |

## Часть 2 — Чтение файла

Собери файл: FAT-таблица (сектор после reserved) содержит 12-битные
кластерные ссылки. Корневой каталог после FAT. Запись каталога 32 байта:
имя (8+3), атрибут, размер (u32 LE), первый кластер (u16 LE), время/дата.

Реализуй:

1. Найти в корневом каталоге файл `SECRET.TXT`;
2. Пройти цепочку кластеров через FAT;
3. Собрать байты и вывести содержимое.

## Подсказки

- FAT12 кластер хранится в 3 байтах на 2 кластера: `fat[0]|fat[1]<<8`,
  `fat[1]|fat[2]<<8` — аккуратно с битами (взять по 12).
- Данные кластера: `sector = fat_start + sectors_per_fat*2 + (cluster-2)*sectors_per_cluster`.
- Цепочка: `next = fat_value(cluster)`; конец — `>= 0xFF8`.
- Имя файла — uppercase без точки: `SECRET  TXT` → `SECRET.TXT`.
