# Миссия 048 — Тихий сканер

> Уровень: `★★☆☆☆` · Тема: порт-сканер

Тихий сканер: не ломиться в дверь, а пройти по улице и посмотреть, где горит свет. Джез впервые
получает задание «просто посмотреть».
— Разведка — это искусство не торопиться, — CROW передаёт ей список адресов. — Те, кто спешит,
шумят.
Джез идёт по адресам и слушает, какие двери отвечают.

---

## Данные

`data/048/ports.txt` — открытые порты, по одному на строку. Скан
считается выполненным по диапазону 1–1024 на `127.0.0.1`; остальные
порты закрыты.

## Часть 1 — Результат скана

Прочитай `ports.txt` и выведи открытые порты через пробел, в порядке
строк файла:

### Выход

```text
OPEN: 22 80 1200 8080
```

## Часть 2 — Отчёт

Выведи итоговый отчёт скана: сводка по диапазону 1–1024 (константа) и
время скана в мс (для этого задания фиксировано — 213 мс), затем —
список открытых портов как в части 1:

### Выход

```text
SCANNED 1024 ports in 213ms
OPEN: 22 80 1200 8080
```

## Подсказки

- «Закрытый» порт — которого нет в `ports.txt`; он в отчёт не входит.
- Порядок открытых портов — порядок строк файла, а не возрастание
  номера.
- Числа 1024 и 213 — константы отчёта: не выводи ничего лишнего.
