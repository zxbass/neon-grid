# 208 — Давление GC

> Уровень: `★★★★☆` · Тема: GC · несканируемые объекты

CROW прислал индекс на две тысячи ключей. Джез строит мапу на строках — и Дон замечает, как терминал
задумывается после каждого прогона.
— Сборщик ходит по всем корням, — Зен показывает на схему. — Строки он проверяет. А фиксированные
байты — нет. Разница — в давлении.
Джез снижает давление.

---

## Данные

- `data/208/index.bin` — 2000 записей: ключ `[16]byte` + значение `uint64` в
  little-endian

## Часть 1

Построй мапу и выведи три ключа с максимальными значениями:
`TOP1: <ключ hex>` … `TOP3: <ключ hex>` (сортировка по значению по убыванию,
при равенстве — по ключу hex по возрастанию).

## Часть 2

Тот же вывод.

Тест проверяет, что часть 2 выполняется **не более чем за 1000 аллокаций**:
строковые ключи (`string(ключ)`) дают ~2000+ аллокаций — используй ключи
`[16]byte`, их GC не сканирует и они не требуют конвертации.
