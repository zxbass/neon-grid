# Миссия 037 — CRC32-страж

> Уровень: `★★☆☆☆` · Тема: CRC32 с нуля

CRC32 — сторож у дверей архива: тридцать два бита, которые следят, чтобы ни один байт не изменился.
Но сторожей учат обходить.
— Контрольная сумма — это подпись, — Прах смотрит на столбик шестнадцатеричных цифр. — А подписи
подделывают.
Джез учится считать и сверять. Пока просто считать.

---

## Часть 1 — Побитовый CRC

Реализуй CRC-32 IEEE 802.3:

```text
crc = 0xFFFFFFFF
for byte in data:
    crc ^= byte
    for _ in 0..8:
        if crc & 1: crc = (crc >> 1) ^ 0xEDB88320
        else: crc >>= 1
return crc ^ 0xFFFFFFFF
```

Вычисли для строк `NEON` и `GRID`:

### Выход

```text
NEON: 0x???????? (посчитай сам — сверь с zlib.crc32)
GRID: 0x???????? 
```

(проверка: `zlib.crc32(b"NEON")` — число 32-бит; выведи в hex.)

## Часть 2 — Таблица на 256

Ускорь: предвычисли таблицу `table[256]` (для каждого байта — результат
8 итераций), потом считай CRC, идя по байтам с `crc = (crc >> 8) ^
table[(crc ^ byte) & 0xFF]`.

Файл `data/037/blob.bin` (64 КБ) и его испорченная копия (последний
байт перевёрнут). Посчитай CRC табличным способом, сверь с побитовым
результатом и посчитай CRC испорченной копии:

### Выход


## Подсказки

- Начальное `0xFFFFFFFF` и финальный XOR `0xFFFFFFFF` обязательны —
  это часть стандарта.
- Полином с отражением: `0xEDB88320` (не `0x04C11DB7`!).
- Сверка: Python `zlib.crc32`, Go `hash/crc32` (таблица IEEE).
