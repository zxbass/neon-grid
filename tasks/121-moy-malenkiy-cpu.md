# Миссия 121 — Мой маленький CPU

> Уровень: `★★★★★` · Тема: эмуляция 8-битного процессора, отладка

Мой маленький CPU: восьмибитный процессор «Плесень-0» — свой, из «Гаража», собранный из того, что
нашлось в ящике. Джез впервые оживляет железо своим кодом.
— Процессор — это часы, — Дон поправляет паяльник. — Идёт — значит, жив. Остановится — значит, мы
зря паяли.
Джез заводит часы.

---

## Часть 1 — Эмулятор

Процессор «Плесень-0»: аккумулятор `A` (8 бит), 256 байт памяти,
программный счётчик `PC`. Команды идут подряд; команды с операндом
занимают **два** байта, без операнда (`HLT`, `PRN`) — **один**:

| Опкод | Мнемоника | Действие |
| ------- | ----------- | ---------- |
| 0x00 | HLT | остановить |
| 0x01 | LDA #imm | `A = imm` |
| 0x02 | ADD #imm | `A = (A + imm) & 0xFF` |
| 0x03 | SUB #imm | `A = (A - imm) & 0xFF` |
| 0x04 | STA addr | `mem[addr] = A` |
| 0x05 | JMP addr | `PC = addr` |
| 0x06 | JZ addr | если `A == 0`, `PC = addr` |
| 0x07 | PRN | вывести `A` как ASCII-символ |
| 0x08 | INP addr | `A = mem[addr]` |

Программа лежит в памяти с адреса 0; `PC` начинает с 0; после каждой
команды `PC` переходит на следующую (`HLT`/`PRN` — на +1, остальные —
на +2, а `JMP`/`JZ`-переход переписывает `PC` целиком).

Прогони:

```text
01 4F 07 01 4B 07 00
```

### Выход

```text
OUTPUT: OK
```

(`4F` = 'O', `4B` = 'K', `00` = HLT.)

## Часть 2 — Отладка прошивки

Вшитая прошивка должна выводить код доступа, но выводит мусор:

```text
01 43 07 01 4F 07 00
```

Сравни с рабочей:

```text
01 43 07 01 54 07 00
```

Отладь: прогони обе на своём эмуляторе, найди позицию, где они
расходятся, и восстанови, что должна была вывести битая прошивка.

### Выход

```text
BIT: BYTE 5 (0x4F -> 0x54)
BROKEN OUTPUT: CO
WORKING OUTPUT: CT
```

(первая печатает `CO`, вторая — `CT`; а вот настоящий код доступа спрятан
в длинной прошивке ниже — прогони её и достань его.)

Длинная прошивка (символы считаются арифметикой, а не вручную):

```text
01 4F 07 02 01 07 03 0B 07 02 09 07 00
```

### Финальный выход

```text
CODE: OPEN
```

(`0x4F` = 'O'; `+1` → 'P'; `-0x0B` → 'E'; `+9` → 'N'.)

## Подсказки

- `PRN` выводит **значение** `A`, не его hex-представление.
- `SUB` — с учётом переполнения: `(A - imm) mod 256`.
- Для части 2 построй цикл `JZ`/`JMP`, если нужно повторить участок —
  или просто прогони вручную и сверь с первым байтом расхождения.
