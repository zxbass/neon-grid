# Миссия 125 — Гифка наоборот

> Уровень: `★★★★★` · Тема: GIF-энкодер, LZW, палитры, кадры

GIF-ка наоборот: анимация, которая крутится задом наперёд, и в обратном ходе видно то, что было
скрыто. Джез учится смотреть в прошлое кадров.
— Время можно повернуть, — Син проводит пальцем по экрану. — Просто не все кадры это переживают.
Джез разворачивает время.

---

## Часть 1 — Один кадр

Собери GIF87a из сырых пикселей (RGB, ширина×высота ≤ 64×64, без
прозрачности):

- сигнатура `GIF87a`;
- Logical Screen Descriptor: ширина, высота (u16 LE), флаги
  (`0xF0` = 16 цветов, global color table), bg=0, aspect=0;
- глобальная палитра: 16 цветов × 3 байта (RGBA-нет, просто RGB);
- Image Descriptor (`0x2C` + 9 байт) + `LZW_MIN` (мин. код 4) +
  sub-blocks с LZW-сжатыми индексами палитры + `0x00`;
- Trailer `0x3B`.

Палитру собери жадным квантованием (как 039, до 16 цветов). Проверь,
что твой файл открывается и что декодер из 093 читает его обратно.

### Выход

```text
GIF87a 32x24 colors=16
bytes=0x1A0
ROUNDTRIP: OK
```

## Часть 2 — Анимация и бюджет

Добавь Graphic Control Extension (`0x21 0xF9` + 4 байта + `0x00`) перед
каждым кадром: delay в 10 мс (`0x0A` = 100 мс), disposal = 1 (не стирать).

Собери анимацию из 4 кадров и ужми её так, чтобы каждый следующий кадр
писал **только отличия** от предыдущего (прозрачный индекс = 16).
Сравни размеры:

```text
FULL: 4520 bytes
DIFF: 1871 bytes   <- экономнее в 2.4 раза
```

## Подсказки

- LZW в GIF: коды 4..12 бит (мин. код растёт от `LZW_MIN`), Clear code
  и EOI — как в 093; словарь на 4096.
- Индексы в данных — это **индексы палитры**, а не сами цвета.
- Diff-кадры: прозрачный пиксель = индекс за пределами палитры
  (`0x10`), disposal=1 значит «не затирай под собой».
- Бюджет байтов решается палитрой: меньше цветов → меньше бит на код.
