# Миссия 009 — Печать кузнеца

> Уровень: `★★☆☆☆` · Тема: контрольные суммы

Кузнец, который точит для «Гаража» навесные замки, попросил проверить новую пломбу: пять байт
данных, запечатанных контрольной суммой. Если печать сходится — груз настоящий, если нет — за
пломбой кто-то уже лазил.
— Печать должна быть как характер, — говорит кузнец, вытирая руки ветошью. — Один раз проверенная —
и видно, человек она или подделка.
Джез считает сумму, и железный ящик на верстаке тихо щёлкает замком.

---

## Часть 1 — Сумма в кольце

Печать — это одно 32-битное слово-аккумулятор `acc`, в которое по очереди подмешиваются
байты груза. Данные идут **побайтово** (байт 0, байт 1, …), а не словами: 32-битное слово
здесь только сам `acc`.

Алгоритм печати:

1. Начинай с `acc = 0x5A5A5A5A`.
2. Для каждого байта `b` груза: `acc = ((acc << 5) | (acc >> 27)) ^ b`.
   Слово прокручивается влево на 5, и в него XOR-ится очередной байт (XOR меняет только
   младшие 8 бит).
3. Конечная печать — `acc & 0xFFFFFFFF`, выведи в hex.

Любое изменение байта груза меняет печать.

Ручная проверка на реальном грузе `cargo.bin` (байты `01 02 03 04 05`, 5 байт):

- acc = 0x5A5A5A5A
- `<<5 | >>27` от 0x5A5A5A5A = 0x4B4B4B4B, XOR 0x01 → 0x4B4B4B4A
- от 0x4B4B4B4A: 0x69696949, XOR 0x02 → 0x6969694B
- от 0x6969694B: 0x2D2D296D, XOR 0x03 → 0x2D2D296E
- … и так до конца файла (осталось два байта).

### Выход

```text
SEAL: 0xXXXXXXXX
```

### Данные

- `data/009/cargo.bin` — груз части 1: 5 байт `01 02 03 04 05`

## Часть 2 — Проверка партии

Файл `batch.bin`: первые 4 байта — заявленная печать (u32 LE), дальше — груз.
Посчитай печать груза по алгоритму части 1 (4-байтовое поле в расчёт не входит)
и сравни с заявленной:

- совпало — `SEAL OK (0x%08X)` с фактической печатью;
- не совпало — `SEAL BAD (expected 0x%08X, got 0x%08X)`, где `expected` — заявленная
  печать из файла, `got` — посчитанная.

### Пример

```text
SEAL BAD (expected 0xDEADBEEF, got 0x12345678)
```

### Данные

- `data/009/batch.bin` — партия: 4 байта заявленной печати (u32 LE) + груз `01 02 03 04 05`

## Подсказки

- Поворот влево: `(x << 5) | (x >> (32 - 5))`, но только если `x`
  беззнаковый 32-бит; в языках с фиксированной шириной (Go, Rust, C)
  используй `uint32`, иначе сдвиг `>>` будет арифметическим.
- В Python не забудь `& 0xFFFFFFFF` после каждого шага.
- Данные идут побайтово: `for _, b := range cargo { acc = rotl5(acc) ^ uint32(b) }`.
- В части 2 читай заявленную печать как LE.
