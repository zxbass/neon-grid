# Миссия 122 — Рукопожатие из гаража

> Уровень: `★★★★★` · Тема: Диффи-Хеллман, HMAC, защита от повтора

Рукопожатие из гаража: Диффи-Хеллман, обмен ключами без встречи. Джез учится договариваться с незнакомцем по проводам, не открывая секрета.
— Доверие — это математика, — Зен выводит на доске формулы. — И в ней нет места чувствам.
Джез считает доверие.

---

## Часть 1 — Обмен ключами

Протокол «гараж» работает на маленьком модуле (как миссия 030):

- общее простое `p = 23`, генератор `g = 5`;
- каждая сторона выбирает секрет: `a` и `b`;
- по каналу летят только `A = g^a mod p` и `B = g^b mod p`;
- общий ключ: `S = B^a mod p = A^b mod p`.

Ты — сторона `a = 6`, брокер — `b = 15`. Вычисли `A`, `B` и общий ключ.

### Выход

```
A: 8
B: 19
SHARED: 2
```

(проверь: `5^6 mod 23 = 8`, `5^15 mod 23 = 19`,
`19^6 mod 23 = 2` и `8^15 mod 23 = 2` — совпало.)

## Часть 2 — Подпись и защита от повтора

Каждое сообщение:

```
nonce(u32 BE) | seq(u32 BE) | data | tag
```

где `tag = crc16_ccitt(S || nonce || seq || data)` (CRC-CCITT из 016),
`S` — общий ключ из части 1 (1 байт, 0x02).

Собери сервер, который:

1. проверяет `tag` — иначе `DROP`;
2. держит окно `seq` размером 64: принятые `seq` запоминаются, **повторный
   `seq` → `REPLAY DROP`** (и ответ на такой пакет не шлётся);
3. отвечает `ACK <seq>`.

Прими банку `nonce=0x11223344 seq=5 data="AWAKE"` и повтори её же —
второй раз сервер должен ответить `REPLAY DROP`.

### Выход

```
SEQ 5: ACK
SEQ 5 (replay): REPLAY DROP
```

## Подсказки

- Модульная арифметика — переиспользуй `pow(a, b, mod)` из 030.
- Перехватив `A` и `B`, ты можешь посчитать общий ключ, зная только
  свой секрет — это и есть смысл DH.
- Окно повторов: массив/битмаска из 64 `seq`; окно двигается вперёд,
  «старые» `seq` всегда отбрасываются.
