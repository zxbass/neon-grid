# Миссия 109 — Инъекция «Игла»

> Уровень: `★★★★☆` · Тема: инъекция кода, patch payload

Игольная инъекция: вставить свой код в чужую программу так, чтобы она этого не заметила. Джез учится
быть иглой.
— Игла не ломает ткань, — Син проводит пальцем по воздуху. — Она просто проходит сквозь неё.
Джез становится иглой.

---

## Данные

- `data/109/target.bin` — байткод VM «IronCore» (опкоды как в 107, таблица ниже);
  32 байта, две инструкции перехода: `JMP` на 0x00 и `JZ` на 0x1C.

## VM «IronCore»

| Опкод | Название | Длина |
| ------- | ---------- | ----- |
| 0x01 | PUSH imm32 (LE) | 5 |
| 0x02 | POP | 1 |
| 0x03 | DUP | 1 |
| 0x04 | ADD | 1 |
| 0x05 | SUB | 1 |
| 0x06 | MUL | 1 |
| 0x07 | AND | 1 |
| 0x08 | JMP target | 2 |
| 0x09 | JZ target (pop; если 0 — jump) | 2 |
| 0x0A | CMP (pop a, pop b, push b==a) | 1 |
| 0x0B | LOAD var (u16) | 3 |
| 0x0C | STORE var (u16) | 3 |
| 0x0D | CALL func (u16) | 3 |
| 0x0E | RET | 1 |
| 0x0F | HLT | 1 |

Правила симуляции (используются и в части 2):

- стек и переменные `x[65536]` — беззнаковые 32-битные, начальное значение 0,
  вход `x0 = 0`;
- `STORE` в переменную `0xFFFE` — «экран»: младший байт значения
  добавляется в выходной поток;
- `JMP`/`JZ`: операнд — беззнаковый байт, **абсолютная позиция от начала
  кода** (как `jump 0x0030` в 107); `JZ` снимает значение со стека
  и прыгает, если оно 0;
- `HLT` — остановка, код выхода 0.

## Часть 1 — Вставка кода

В начало файла (offset 0) вставь «иглу» из 6 байт:

- `PUSH 0` (0x01 + 4 байта LE);
- `HLT` (0x0F).

Оригинальный код сдвинь на 6 байт. Для каждой инструкции `JMP`/`JZ`,
**находящейся в сдвинутом оригинале** (позиция ≥ 6), увеличь операнд
(цель перехода) на 6.

### Выход

```text
INJECTED 6 bytes @ 0x0000
JMP FIXED: 2 relocations
```

## Часть 2 — Троянский вход

Собери полноценную инъекцию (`payload`): для каждого символа `c` строки
`INFECTED` — `PUSH c` + `STORE 0xFFFE` (по 8 байт, всего 64), затем
`JMP 66` (`0x08 0x42`) — цель сразу за payload, где начинается
сдвинутый оригинал.

Оригинал сдвинь на длину payload (66 байт) и пересчитай цели его
переходов: `JMP`/`JZ` в позициях ≥ 66 получают операнд += 66.

Эмулируй весь файл (payload + оригинал) по правилам выше и выведи:

### Выход

```text
RUN:
INFECTED
(оригинал продолжает работу)
EXIT: 0
```

## Подсказки

- Релокации: сдвигается цель (операнд) переходов, расположенных в
  сдвинутом коде; переходы внутри вставленного кода не трогай.
- Эмулятор VM — маленький, но обязателен (это «проверка» выполнения).
- Новая строка после `INFECTED` — символический вывод.
