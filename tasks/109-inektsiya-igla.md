# Миссия 109 — Инъекция «Игла»

> Уровень: `★★★★☆` · Тема: инъекция кода, patch payload

Игольная инъекция: вставить свой код в чужую программу так, чтобы она этого не заметила. Джез учится
быть иглой.
— Игла не ломает ткань, — Син проводит пальцем по воздуху. — Она просто проходит сквозь неё.
Джез становится иглой.

---

## Часть 1 — Вставка кода

Файл `target.bin` — маленький VM-код из 107 (или «Viagon»-код). В
начало (offset 0) вставь свой код:

- `PUSH <n>` (3 байта) + `HLT` (1 байт);
- сдвинь оригинальный код на 4 байта.

Реализуй патчер, который вставляет байты по offset и пересчитывает
JMP-цели (rel8) с учётом сдвига. Выведи:

```text
INJECTED 4 bytes @ 0x0000
JMP FIXED: 2 relocations
```

## Часть 2 — Троянский вход

Задача: код должен вывести на «экран» (stdout в симуляции) строку
`INFECTED` до того, как оригинал начнёт проверку. Реализуй мини-«VM»
или эмулятор (стек + переменные), выполни код с инъекцией и проверь:

### Выход

```text
RUN:
INFECTED
(оригинал продолжает работу)
EXIT: 0
```

## Подсказки

- Релокации: для каждой JMP/JZ с целевой позицией ≥ offset прибавь
  длину инъекции.
- Эмулятор VM — маленький, но обязателен (это «проверка» выполнения).
- Новая строка после `INFECTED` — символический вывод.
