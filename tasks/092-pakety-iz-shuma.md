# Миссия 092 — Пакеты из шума

> Уровень: `★★★★☆` · Тема: модуляция, биты в сигнале

Пакеты из шума: модуляция, несущая, биты — и вот уже из белого шума выплывает сообщение. Джез учится
ловить сигнал там, где другие слышат только помехи.
— Шум — это ещё не конец разговора, — Зен поправляет антенну. — Это просто другой голос.
Джез слушает другой голос.

---

## Часть 1 — Бинарный сигнал

Файл `noise.wav` (8000 Гц, 8-бит). Сигнал — последовательность бит:
каждый бит = 40 мс (320 семплов). Два тона:

- бит `0` — низкая частота (1000 Гц);
- бит `1` — высокая (2000 Гц).

Определи частоту каждого блока по пересечениям нуля (как в 013) и
собери строку бит. Выведи длину и первые 64 бита:

```text
BITS: 10100101... (len=512)
```

## Часть 2 — Байты

Биты идут по 8 в байт (MSB-first). Конвертируй в байты и выведи как
текст, если всё печатное:

```text
BYTES: 0x4E 0x45 0x4F 0x4E ...
TEXT: NEON...
```

Добавь фильтр шума: если в блоке частота не определилась чётко
(пересечения дают значения вне ±15% от номинала) — помечай бит как
`?`. Посчитай долю мусорных бит:

```text
NOISE: 3.1% ambiguous bits
```

## Подсказки

- Частота = crossings / 2 / (длительность в сек).
- Для ASK/FSK-разделения порог частоты между 1500 Гц.
- Печатность байта: 32..126.
