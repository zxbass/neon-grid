# Миссия 118 — Встреча с МЕРКУРИЕМ

> Уровень: `★★★★★` · Тема: игра с ИИ, криптоанализ

Встреча с МЕРКУРИЕМ: старый ИИ Сетки наконец отвечает. Джез впервые разговаривает с тем, кто старше
всей Сетки.
— Ты долго шла, — говорит МЕРКУРИЙ на экране. — Я считал каждый твой шаг.
Джез понимает, что шаги можно считать и за ней.

---

## Данные

- `data/118/riddles.txt` — 5 загадок, по одной на строку:
  `XOR key=<hex> <hex-байты>` (шифр 021), `CAESAR n=<n> <текст>` (022),
  `VIGENERE key=<слово> <текст>` (023, не-буквы пропускаются).
- `data/118/guess.txt` — для части 2: строка `ciphertext: <hex-байты>`,
  строка `candidates: XOR CAESAR VIGENERE` и строка
  `vigenere_key: OMEGA`.

## Часть 1 — Загадка-шифр

МЕРКУРИЙ оставил 5 загадок: для каждой в файле указан шифр и ключ.
Расшифруй строку (переиспользуй функции из миссий 021, 022, 023) и
проверь, что результат состоит только из заглавных букв `A-Z` и
пробелов. Если проверка прошла — загадка решена.

### Выход

```text
ROUND 1/5 OK
ROUND 2/5 OK
ROUND 3/5 OK
ROUND 4/5 OK
ROUND 5/5 OK
KEY: mercury_sees_all
```

## Часть 2 — МЕРКУРИЙ-тест

МЕРКУРИЙ даёт один шифротекст и список из 3 шифров: «один из них».
Перебери всех кандидатов и оцени расшифровку:

- XOR: все ключи `0x00..0xFF`, расшифровка через 021;
- CAESAR: все сдвиги `1..25`, через 022;
- VIGENERE: ключ `OMEGA` из `guess.txt`, режим «пропускать не-буквы».

Оценка — доля символов `A-Z` и пробела. Побеждает кандидат с
максимальной долей; при равенстве — тот, у кого есть пробел; затем —
порядок перечисления (XOR, CAESAR, VIGENERE).

### Выход

```text
CIPHER GUESSED: XOR (key 0x4A)
DIALOGUE COMPLETE: 5/5
```

## Подсказки

- Переиспользуй код — это финальная проверка навыков, а не новая тема.
- Hex в файле — с пробелами, регистр не важен.
- Оценка печатности отсекает все шифры, кроме правильного.
