# Миссия 057 — Сплетни Рейвенов

> Уровень: `★★★★☆` · Тема: gossip, peer-to-peer

Сплетни райенов: новости расходятся по Сетке слухами — каждый узел передаёт соседу. Джез наблюдает,
как слух рождается, путешествует и возвращается уже другим.
— Слух — это вирус, — CROW щёлкает зажигалкой. — Им можно заразить весь квартал, если знать, с кого
начать.
Джез отслеживает слух по узлам и считает, за сколько волн он докатился до всех.

---

## Данные

Файл `data/057/nodes.txt` — топология: первая строка — число узлов N,
далее по строке на узел: `номер: соседи через пробел`.

```text
5
0: 1 2
1: 0 3
2: 0 4
3: 1
4: 2
```

## Часть 1 — Флуд

Узел 0 получает сообщение и рассылает его всем соседям; каждый узел
пересылает полученное сообщение своим соседям, кроме отправителя.
Сообщения не дублируются. Выведи порядок, в котором узлы впервые
получили сообщение (BFS от узла 0, соседи в порядке списка).

### Выход

```text
ORDER: 0 1 2 3 4
```

## Часть 2 — Волны сплетен

Слух распространяется волнами: за одну волну каждый узел, узнавший
слух в прошлой волне, передаёт его **всем** соседям. Номер волны
узла — когда он узнал слух. Выведи узлы по волнам (внутри волны —
по возрастанию), максимум и среднее по всем узлам.

### Выход

```text
WAVE 0: 0
WAVE 1: 1 2
WAVE 2: 3 4
MAX WAVE: 2
AVG WAVE: 1.20
```

## Подсказки

- Номер волны = расстояние BFS от узла 0.
- Среднее — арифметическое номеров волн всех N узлов, формат `%.2f`.
- Топология связна, `UNREACHABLE` в этих данных не случится.
