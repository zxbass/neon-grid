# Миссия 057 — Сплетни Рейвенов

> Уровень: `★★★★☆` · Тема: gossip, peer-to-peer

Сплетни райенов: новости расходятся по Сетке слухами — каждый узел передаёт соседу. Джез наблюдает,
как слух рождается, путешествует и возвращается уже другим.
— Слух — это вирус, — CROW щёлкает зажигалкой. — Им можно заразить весь квартал, если знать, с кого
начать.
Джез отслеживает слух по узлам и видит, где он впервые соврал.

---

## Часть 1 — Топология и флуд

N узлов (N до 100). Каждый узел знает список соседей. Узел 0 получает
сообщение и рассылает его всем соседям; каждый узел пересылает
полученное сообщение своим соседям, кроме отправителя. Сообщения
не дублируются (поиск по id).

Вход:

```text
5
0: 1 2
1: 0 3
2: 0 4
3: 1
4: 2
```

Сообщение с узла 0. Выведи порядок, в котором узлы впервые получили
сообщение:

```text
ORDER: 0 1 2 3 4
```

## Часть 2 — Гонка сплетен

Теперь узлы пересылают сообщение **случайному** соседу каждые 100 мс
(«сплетня»), а не всем сразу. Цель — вывести время в «волнах» (шагах
по 100 мс), за которое **все** узлы узнают сообщение. Запусти симуляцию
10 раз на случайной связной топологии (сгенерируй сам: N=30, каждый
узел имеет 2–4 соседа) и выведи среднее:

### Выход

```text
AVG WAVES: 7.3 (min 5 max 11)
```

## Подсказки

- BFS с «не ходим к тому, от кого пришло» — для части 1.
- Для части 2 узел хранит: известные id сообщений + очередь соседей.
- Убедись, что топология связна — иначе сообщение не дойдёт, это
  зачётный кейс (`UNREACHABLE`).
