# Миссия 129 — Селф-хилинг

> Уровень: `★★★★★` · Тема: многостадийный взлом, самодиагностика

Селф-хилинг: программа, которая лечит сама себя. Джез учится писать код, который не сдаётся.
— Боль — это сигнал, — Зен говорит это спокойно. — А сигнал можно обработать.
Джез учится обрабатывать боль.

---

## Данные

- `data/129/gate.bin` — образ «двери»: байты `0..3` — `version` (`u32 LE`),
  байты `4..260` — область 256 байт, XOR-нутая ключом `0x5A` (021).
- `data/129/gate.damaged` — тот же образ, но в стадии 3 испорчены
  3 байта блока 2 (содержимое RLE-потока).
- `data/129/gate.mirror` — зеркало: `MIRR` (4 байта), число блоков
  (`u16 LE`), 4 блока по 16 байт, `rleLen` (`u16 LE`) и здоровый
  RLE-поток (для сверки).

Расшифрованная область (стадия 3): `rleLen` (`u16 LE`, байты `0..1`),
RLE-поток из `rleLen` байт (формат 032: тройки `count u16 LE` +
`value`), затем 4 контрольные суммы `crc16` блоков (`u16 LE` каждая;
016: полином `0x1021`, init `0xFFFF`). RLE распаковывается ровно в
64 байта — ядро из 4 блоков по 16.

Ядро (64 байта):

- `0..4` — `AUTH`, байт `4` — пробел, `5..14` — пароль `NEON_RAVEN`,
  байт `15` — ноль;
- `16..19` — `seq` (`u32 BE`);
- `20..21` — магия `0x5A5A` (`u16 LE`);
- `22..23` — `crc16` байтов `0..21`;
- `24..29` — код доступа (6 десятичных цифр);
- `30..31` — `crc16` цифр кода;
- `32..63` — заполнение.

## Часть 1 — Пайплайн стадий

Прогони 7 стадий по `gate.bin`:

1. проверь `version >= 7`;
2. расшифруй область ключом `0x5A` (проверка: длина 256);
3. распакуй RLE, проверь `crc16` каждого блока;
4. проверь `AUTH` и пароль;
5. проверь магию `0x5A5A` и `crc16` байтов `0..21`;
6. проверь цифры кода и их `crc16`;
7. выведи код доступа.

### Выход

```text
STAGE 1: OK (version=9)
STAGE 2: OK (len=256)
STAGE 3: OK (blocks=4)
STAGE 4: OK (auth=NEON_RAVEN)
STAGE 5: OK (magic=0x5A5A crc16=0x76AB)
STAGE 6: OK (code_crc=0x987A)
STAGE 7: CODE=704213 ACCESS GRANTED
```

## Часть 2 — Самовосстановление

Тот же пайплайн по `gate.damaged`: стадия 3 находит блок, чей `crc16`
не сходится, и сообщает повреждение. Восстанови блок из `gate.mirror`
(блок 2 лежит по смещению `0x16`: 6 байт заголовка + 16 байт блока 1),
проверь `crc16` восстановленного блока, продолжи стадии 4–7 и выведи
отчёт.

### Выход

```text
DAMAGE: stage 3 block #2
HEALED: using mirror copy (offset 0x16)
RESULT: ACCESS GRANTED (self-healed 1/1)
```

## Подсказки

- У каждой стадии фиксируй «канонический» вид: длину, CRC, магию.
  Проверка — это сравнение с каноном.
- Self-heal — это не магия: это резервная копия (зеркало) + соглашение,
  где лежит блок.
- Строительно переиспользуй 021 (XOR), 032 (RLE), 016 (CRC16) — все
  инструменты уже у тебя в руках.
