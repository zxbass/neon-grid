# Миссия 129 — Селф-хилинг

> Уровень: `★★★★★` · Тема: многостадийный взлом, самодиагностика

Селф-хилинг: программа, которая лечит сама себя. Джез учится писать код, который не сдаётся.
— Боль — это сигнал, — Зен говорит это спокойно. — А сигнал можно обработать.
Джез учится обрабатывать боль.

---

## Часть 1 — Пайплайн стадий

`gate.bin` — образ с 10 стадиями. Каждая стадия возвращает байты для
следующей. Стадии:

1. читай `version` (u32 LE, байты 0–3), должно быть `>= 7` (как 119);
2. XOR-расшифровка байтов 4..259 ключом `0x5A` (как 021);
3. внутри — 16-бит длина `L` (u16 LE) и данные: RLE-распаковать (032);
4. распакованное — LZW-коды? нет, это байты: возьми из них пароль
   `AUTH <pw>` (как 119);
5. проверь пароль CRC16 == `0x5A5A` (016);
6. из расшифрованного достань `seq` (u32 BE) и ключ следующей стадии;
7. «дверь»: HTTP-запрос с `AUTH` и `seq` на `127.0.0.1:1999` (044-стиль);
8. ответ содержит hex-ключ; расшифруй им следующую стадию;
9. на «экране» TUI (060) появится код доступа;
10. код — 6 десятичных цифр; последняя стадия.

Каждая стадия умеет себя **проверить** (CRC, длина, магия) и вывести
`STAGE N: OK` или `STAGE N: CORRUPT -> self-heal`.

### Выход

```text
STAGE 1: OK (version=9)
STAGE 2: OK (len=512)
...
STAGE 10: CODE=704213 ACCESS GRANTED
```

## Часть 2 — Самовосстановление

Испорть образ: в `gate.bin` подмени 5 байт в стадии 3 (RLE-данные).
Твой пайплайн должен:

1. поймать битую стадию по CRC/длине;
2. восстановить её: в RLE-потоке найти повреждённый блок и
   пересобрать (или взять запасную копию из хвоста образа);
3. продолжить со стадии 4, не перезапуская всё с нуля.

Выведи отчёт и итог:

```text
DAMAGE: stage 3 block #12
HEALED: using mirror copy (offset 0x4A000)
RESULT: ACCESS GRANTED (self-healed 1/1)
```

## Подсказки

- У каждой стадии фиксируй «канонический» вид: длину, CRC, магию.
  Проверка — это сравнение с каноном.
- Self-heal — это не магия: это резервная копия (зеркало в хвосте
  файла) + соглашение, где она лежит.
- Строительно переиспользуй 021 (XOR), 032 (RLE), 016 (CRC16), 044
  (сетевой запрос) и 060 (TUI) — все инструменты уже у тебя в руках.
