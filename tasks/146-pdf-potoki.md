# 146 — PDF-потоки

> Уровень: `★★★★★` · Тема: PDF · потоки

PDF с чьим-то отчётом: объекты, потоки, ссылки. Джез впервые разбирает документ, который умеет быть целым, только если все его части врут одновременно.
— Документ — это договор, — CROW смотрит на объекты. — Между читателем и тем, кто его писал.
Джез читает договор.

---

## Данные
- `data/146/doc.pdf`

## Часть 1
Верни:
```
CATALOG: obj1
PAGES: obj2 COUNT=1
PAGE: obj3
STREAM: obj4
```

## Часть 2
Извлеки содержимое потока (объект 4) и верни `CONTENT: <текст>`.
