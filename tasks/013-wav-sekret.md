# Миссия 013 — WAV-секрет

> Уровень: `★★★☆☆` · Тема: WAV, аудиосемплы

На голосовой ящик «Гаража» оставили сообщение из девяти цифр, но прослушать его нельзя: вместо
записи — файл, который звучит как помехи. Кто-то зашифровал номер в тональном наборе.
— В шуме тоже есть голоса, — говорит Син, и впервые её голос звучит уверенно. — Надо только уметь их
считать.
Джез раскладывает сигнал на частоты и собирает из них цифры. Цифры складываются в номер. Номер ведёт
куда-то вверх.

---

## Часть 1 — Разбор WAV

Формат RIFF/WAVE:

| Смещение | Поле |
| ---------- | ------ |
| 0 | `RIFF` |
| 8 | `WAVE` |
| 12 | `fmt`, размер 16 |
| 22 | audio format (u16 LE) |
| 24 | число каналов (u16 LE) |
| 26 | sample rate (u32 LE) |
| 34 | bits per sample (u16 LE) |
| 36 | `data` + размер данных |
| 44 | семплы |

Выведи:

```text
RATE=8000 CH=1 BITS=16 SAMPLES=8000 DURATION=1.000s
```

## Часть 2 — DTMF-детектор

Семплы — 16-битные LE (signed). Файл содержит последовательность
тонов DTMF (двухчастотных). Для каждого блока из 800 семплов определи
присутствующие частоты: для каждой частоты таблицы посчитай мощность
(FFT, фильтр Гёрцеля или корреляция) и выбери две с максимальной
мощностью — по одной из низкой (697/770/852/941) и высокой
(1209/1336/1477) групп.

Таблица DTMF (клавиши):

| | 1209 | 1336 | 1477 |
| --- | --- | --- | --- |
| **697** | 1 | 2 | 3 |
| **770** | 4 | 5 | 6 |
| **852** | 7 | 8 | 9 |
| **941** | * | 0 | # |

Определив две частоты, найди клавишу. Между тонами — тишина
(пропусти блоки, где уровень ниже 1/10 пика файла).

### Выход

```text
KEYS: 5 1 9 1 8 0
```

## Подсказки

- Число семплов = размер data / (channels * bits/8).
- Мощность частоты f на блоке: `|Σ x[n]·e^(−2πi·f·n/sr)|` (или FFT:
  бины 256-точечного БПФ с шагом `sr/256` ≈ 31 Гц — бери ближайший).
- Для точности бери блок из середины каждого тона, а не его границы.
- Частоту подбирай к ближайшей из таблицы (697/770/852/941 и
  1209/1336/1477).
- В блоках тишины ничего не выводи.
