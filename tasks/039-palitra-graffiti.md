# Миссия 039 — Палитра «Граффити»

> Уровень: `★★★☆☆` · Тема: квантование цветов, палитры

Граффити на стенах нижнего уровня — это палитры: восемь цветов, а за ними целые послания. Крем
утверждает, что в граффити зашит маршрут к складу, где «лежит всё».
— Цвет — это код, — он тычет пальцем в стену. — Только читать его умеют немногие.
Джез раскладывает палитру по индексам и находит путь.

---

## Часть 1 — Ближайший цвет

Палитра «Тира» (16 цветов):

```text
0:(0,0,0) 1:(255,0,0) 2:(0,255,0) 3:(0,0,255)
4:(255,255,0) 5:(255,0,255) 6:(0,255,255) 7:(255,255,255)
8:(128,128,128) 9:(128,0,0) 10:(0,128,0) 11:(0,0,128)
12:(128,128,0) 13:(128,0,128) 14:(0,128,128) 15:(64,64,64)
```

Для каждого входного RGB найдите индекс палитры с минимальным
квадратом евклидова расстояния (`dr²+ dg² + db²`). Вход — строки
`R G B`:

```text
255 0 128
0 255 0
12 12 12
```

### Выход

```text
255 0 128  -> 5
0 255 0    -> 2
12 12 12   -> 0
```

## Часть 2 — Изображение

Вход — 24-бит BMP (ширина, высота кратны 8). Проквантуй каждый пиксель
до 4-бит (индексы палитры), упакуй по 2 пикселя на байт (старший
ниббл — левый пиксель). Сохрани результат как файл `quant.raw` и
выведи средний суммарный квадрат ошибки по всем пикселям:

### Выход

```text
MSE: 12.34
WROTE quant.raw (0x??? байт)
```

## Подсказки

- Квадрат расстояния: не бери корень, сравнивай квадраты.
- Равные расстояния — бери меньший индекс.
- MSE = сумма `dr²+dg²+db²` по всем пикселям / число пикселей.
