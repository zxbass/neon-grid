# Миссия 008 — Часы Синдиката

> Уровень: `★★☆☆☆` · Тема: таймстампы, DOS-время

Часы у въезда в «Гараж» показывают время то на семь часов вперёд, то на сорок лет назад. Кто-то вживил в них прошивку «Синдиката» с датами сделок, зашитыми в формат DOS.
— Время — валюта, — Зен вертит циферблат. — И у каждого должника своё.
Джез раскладывает даты по полочкам: год, месяц, день — и понимает, что кто-то платит по часам, которых ещё не существует.

---

## Часть 1 — Разбор времени

32-битный таймстамп:

- биты 0–4: секунды / 2 (0–29)
- биты 5–10: минуты (0–59)
- биты 11–15: час (0–23)
- биты 16–20: день месяца (1–31)
- биты 21–24: месяц (1–12)
- биты 25–31: год с 1980 (0–127)

Вход — hex-значения: `000020B3 00005000 0000FFFF`

Выведи:

```
1980-01-01 00:00:00
1980-01-02 00:02:00
2099-12-31 23:59:58
```

Проверь первое: `0x20B3` = `0b0010 0000 1011 0011` → час=0, мин=0,
сек=0, день=1, месяц=1, год=0 → `1980-01-01 00:00:00`.

## Часть 2 — Свежие файлы

Дан список таймстампов. Выведи тот, который **самый свежий** (максимум
по времени), и разницу в секундах между максимальным и минимальным.

### Вход

```
000020B3 00005000 00004000 00007FFF
```

### Выход

```
LATEST: 2049-12-31 23:59:58
DIFF: 2208988800
```

## Подсказки

- Извлечение битов: `(ts >> s) & mask`.
- Для разницы переводи всё в UNIX-секунды: `year*31536000 + month...` —
  или лучше используй встроенные функции даты, если язык позволяет.
- Год = `1980 + field`, месяц 1-индексован.
