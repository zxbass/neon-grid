# Миссия 016 — Прошивка терминала

> Уровень: `★★★☆☆` · Тема: чек-суммы, прошивки

Терминал кассы на заправке перестал принимать оплату ровно в полночь. Прошивка разделена на блоки, у
каждого — контрольная сумма, и один блок повреждён.
— Терминал — как сердце, — Дон разводит руками. — Не починишь блок — остановится весь район.
Джез проверяет блоки один за другим, и в одном из них сумма не сходится на один бит. Одного бита
достаточно, чтобы весь квартал остался без кофе.

---

## Часть 1 — Простая сумма

Прошивка `term.bin` — образ памяти: 768 байт (3 блока по
**256 байт**). Каждый блок завершается одним байтом чек-суммы, который
считается так: сумма всех байт блока (без последнего) по модулю 256,
инвертированная (`~sum & 0xFF`).

Выведи для каждого блока:

```text
BLOCK 00 checksum OK
BLOCK 01 checksum BAD (got=0x7A want=0x85)
```

## Часть 2 — Прошивка с адресом

Более сложный вариант: блоки теперь начинаются с 4-байтного адреса
загрузки (u32 LE). Чек-сумма последних 2 байт блока — это CRC-16
(полином `0x1021`, начальное значение `0xFFFF`, как CRC-CCITT
«нормальный», без final XOR) от всех байт блока, включая адрес, но
без самих 2 байт чек-суммы.

Найди блоки с битой чек-суммой и выведи их адреса:

```text
BAD: 0x00000000
BAD: 0x0000FF00
GOOD: 0x00008000
```

## Подсказки

- CRC-CCITT: таблица или побитовая реализация, `poly=0x1021`,
  `init=0xFFFF`, без отражения, вывод без `xorout`.
- В части 1 инверсия обязательна: `~sum & 0xFF`.
- В части 2 размер блока = `4 + data + 2`, где `data` = 250 байт.
