# Миссия 090 — Отпечаток «Феникс»

> Уровень: `★★★★☆` · Тема: форензика, временные метки, удаление

Отпечаток феникса: после удаления остаётся след, и по следу можно восстановить всё. Джез впервые
понимает, что в Сетке ничего не исчезает навсегда.
— Феникс сгорает, но пепел помнит, — Зен ставит перед Джез пустую чашку. — И по пеплу можно узнать,
кто он был.
Джез читает пепел.

## Часть 1 — Удалённые строки

Файл `mem.dmp` — срез памяти. Удалённые строки часто лежат в памяти
дольше жизни. Просканируй дамп на печатные ASCII-строки длиной ≥ 12
и выведи все, содержащие подстроки `http`, `ssh`, `password`, `key`,
`/home/`:

## Часть 2 — Хронология

В логах `auth.log` есть записи входа. Формат строки:

```text
<ГГГГ-ММ-ДД ЧЧ:ММ:СС> <login|logout> user=<имя> ip=<адрес> key=<отпечаток>

Сопоставь с найденными строками:

1. из `password` извлеки хэш до `"`;
2. в `/home/raven/drop/keys.pem` — загрузи (это текст, 1 строка —
   открытый ключ; отпечаток — второй токен строки);
3. найди в логах все сессии, у которых `key` равен отпечатку из
   `keys.pem`.

Выведи хронологию входов «Феникса» (время, событие, IP):

```text
2039-01-02 03:04:05 login 10.0.0.7
2039-01-02 03:45:00 login 10.0.0.7
2039-01-03 00:12:33 logout 10.0.0.7

## Подсказки

- Строки: сканируй по одному байту, накапливай печатные, сбрасывай на
  непечатном.
- Для «сопоставления» — простой тест: ключ в логе равен ключу из
  `keys.pem` (или хэшу).
- Сортируй по времени, выводи весь профиль активности.
