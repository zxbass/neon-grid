# Миссия 050 — Ловец баннеров

> Уровень: `★★☆☆☆` · Тема: banner grab, fingerprinting

Баннеры сервисов — вывески Сетки: по ним видно, что за софт крутится за дверью и как с ним говорить.
Джез отправляется «читать вывески» по всему кварталу.
— Баннер — это визитка, — Зен кивает на экран. — И по визитке можно понять, кто хозяин.
Джез собирает визитки, и квартал начинает рассказывать о себе сам.

---

## Данные

`data/050/banners.txt` — собранные баннеры: по строке на сервис,
формат `host port баннер` (баннер может содержать пробелы).

## Часть 1 — Сбор баннеров

Прочитай `banners.txt` и выведи каждую строку в нормализованном виде:
`host:port` и баннер через три пробела:

### Выход

```text
127.0.0.1:23   OMEGA-DYNE GATEWAY v2.1
127.0.0.1:8080   Apache/2.4.41 (Unix) mod_ssl/2.4.41
127.0.0.1:1200   NEON-CHAT/0.9 READY
127.0.0.1:2222   OpenSSH_9.6 Ubuntu-3
```

## Часть 2 — Распознавание софта

Сопоставь баннер с вендором по сигнатурам (регистронезависимо):

- содержит `omega` → `OMEGA-DYNE`
- `apache` → `APACHE_HTTPD`
- `neon-chat` → `NEON_CHAT`
- `openssh` → `OPENSSH`
- иначе → `UNKNOWN`

Выведи счётчики по вендорам в алфавитном порядке:

### Выход

```text
APACHE_HTTPD: 1
NEON_CHAT: 1
OMEGA-DYNE: 1
OPENSSH: 1
```

## Подсказки

- Поиск сигнатуры — подстрока в нижнем регистре баннера.
- Счётчики выводи в алфавитном порядке вендоров.
- Если вендор не найден ни по одной сигнатуре — `UNKNOWN`.
