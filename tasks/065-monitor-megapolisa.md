> Уровень: `★★★☆☆` · Тема: системный монитор, /proc

Монитор мегаполиса: счётчики, графики, температура квартала — всё, что можно увидеть, если не
отводить глаз. Джез строит экран, на котором целый город учится дышать.

## Данные

- `data/065/stat.txt` — две выборки `/proc/stat` (строки `cpu user nice
  system idle iowait irq softirq steal`);
- `data/065/meminfo.txt` — `MemTotal` и `MemAvailable` (в kB);
- `data/065/loadavg.txt` — первые 3 числа — загрузка 1/5/15 минут;
- `data/065/procs1.txt`, `data/065/procs2.txt` — две выборки процессов:
  `pid имя utime stime`.

## Часть 1 — Чтение /proc (Linux)

Прочитай файлы и вычисли «моментальный снимок»:

- загрузка CPU: разность суммарных тиков между выборками
  (`Δtotal`) и разность idle (`Δidle`);
  `CPU% = 100 * (Δtotal - Δidle) / Δtotal`;
- память: `used = MemTotal - MemAvailable`, гигабайты — деление
  на 1048576 (kB → GiB), проценты — `used * 100 / MemTotal`
  (целочисленное деление);
- load — первые 3 поля из `loadavg.txt`.

Выведи:

```text
CPU:  12.3%
MEM:  4.2 GiB / 16 GiB (26%)
LOAD: 0.34 0.21 0.18
```

## Часть 2 — Живой монитор

Вычисли `%cpu` каждого процесса из двух выборок:
`%cpu = 100 * (utime2 - utime1) / Δtotal` (тот же `Δtotal`, что в
Части 1). Отсортируй процессы по убыванию `%cpu` (при равенстве —
по возрастанию `pid`), возьми первые 5. Выведи кадр: сводка и таблицу
`pid`, `имя`, `%cpu` (одна цифра после запятой):

## Подсказки

- Строки таблицы: `%-4d %-16s %.1f` — отступы как в примере.
- Сводка: `CPU:  %.1f%%  MEM: %d%%  LOAD: %s` (load — три числа
  через пробел).
- Это симуляция `/proc` из файлов: никаких реальных системных вызовов.
