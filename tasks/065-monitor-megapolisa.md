## Часть 1 — Чтение /proc (Linux)

Прочитай:

- `/proc/stat` — загрузка CPU (строки `cpu ...` с суммарными тиками);
- `/proc/meminfo` — `MemTotal`, `MemAvailable`;
- `/proc/loadavg` — первые 3 числа.

Выведи «моментальный снимок»:

```text
CPU:  12.3%
MEM:  4.2 GiB / 16 GiB (26%)
LOAD: 0.34 0.21 0.18
```

(На не-Linux платформах — сгенерируй тестовые значения.)

## Часть 2 — Живой монитор

Каждые 1 с перерисовывай экран (ANSI `\x1b[H`), внизу — топ-5
процессов по CPU из `/proc/<pid>/stat` (колонки: pid, name, %cpu).
Длительность — 10 с, последний кадр — финальный вывод в файл.

Строка процесса: `pid name cpu` из `/proc/<pid>/stat` — поле 14
(`utime`), дели на общее время CPU с прошлой выборки:

### Выход (последний кадр)

```text
CPU:  7.8%  MEM: 25%  LOAD: 0.20
PID  NAME             CPU%
1    systemd          0.1
204  chrome           3.2
...
```

## Подсказки

- Парсинг `/proc/stat`: возьми две выборки с паузой, дельта utime —
  дельта total, умножь на 100.
- `/proc/<pid>/stat`: поле 2 в скобках, поля после `)` — начинай счёт
  с 3 (utime — поле 14).
- Рисуй только в терминале; при выводе в файл — один кадр.
