# Миссия 025 — Односимвольный взлом

> Уровень: `★★★☆☆` · Тема: брутфорс XOR, эвристика

Односимвольный пароль от сервера Омега-Дайн. Всего один символ — но угадать его нельзя, а вот посчитать — можно. Зен оставил на доске формулу и ушёл пить чай.
— Дверь, которую закрывают на один замок, — он обернулся в дверях. — Открывается одним ключом. Вопрос — каким.
Джез перебирает варианты, и замок щёлкает.

---

## Часть 1 — Полный перебор

Файл `cipher.bin` (несколько КБ) зашифрован побайтовым XOR с одним
ключевым байтом. Для каждого из 256 возможных ключей расшифруй и
посчитай «английскость»: долю байт в диапазонах печатных ASCII +
пробел/перевод строки. Выведи ключ с максимальной оценкой и текст
(первые 200 символов):

```
KEY: 0x42
TEXT: The contract is yours if you can reach the terminal at sector 7...
```

## Часть 2 — Длинный ключ, известная длина

То же самое, но ключ длиной `L=8` байт (повторяется). Известно, что
открытый текст — только печатные ASCII + `\n`. Разбей шифротекст на
колонки по индексу `i mod L` и для каждой колонки подбери байт ключа
по максимальной доле печатных символов. Выведи ключ и полный текст.

### Выход

```
KEY: MERCURY!
TEXT: awake awake awake the meridian is shifting ...
```

## Подсказки

- «Печатные»: `0x20..0x7E` плюс `\n`, `\t`, `\r`.
- Для части 2 колонки по `i mod L` — но не все колонки одной длины;
  обрабатывай аккуратно.
- Если несколько ключей дают одинаковую оценку — выбери тот, у которого
  больше пробелов (пробел — самый частый символ).
