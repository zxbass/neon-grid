# 181 — Ethernet-кадры

> Уровень: `★★★★☆` · Тема: Ethernet · кадры

Кадры Ethernet: шесть байт — чей голос, шесть — чей адрес, два — о чём речь. Джез учится читать первые слова каждого разговора в Сетке.
— Каждый пакет — это письмо, — CROW смотрит на заголовки. — С адресом и обратным адресом.
Джез читает адреса.

---

## Данные
- `data/181/frames.txt` — три кадра hex (без разделителей)

## Часть 1
Верни `FRAME <i>: <SRC> -> <DST> TYPE=<IPv4/ARP>` (MAC в формате `AA:BB:..`).

## Часть 2
Разбери ARP (второй кадр — его payload): htype(2) ptype(2) hlen(1) plen(1) op(2) sha(6) spa(4) ... Верни `ARP: WHO-HAS? SENDER IP=<a.b.c.d> SENDER MAC=<...>`.
