# Миссия 035 — LZ77-вакуум

> Уровень: `★★★★☆` · Тема: LZ77, скользящее окно

Vacuум LZ77 ищет совпадения в прошлом: «это уже было — вернись на сто байт назад». Так архивируют
данные и воспоминания: то, что повторяется, не записывают заново.
— Прошлое — это буфер, — Зен поправляет очки. — Всегда под рукой, всегда чуть-чуть искажён.
Джез распаковывает вакуум и находит в прошлом строку, которая ведёт в будущее.

---

## Часть 1 — Распаковка

Формат потока:

- байт `flag`: бит 7 = 1 → дальше 1 байт **литерал**; бит 7 = 0 → дальше
  2 байта: `offset` (u16 LE) и `length` (u8).
- Копируются `length` байт из уже распакованных данных на расстоянии
  `offset` назад (начиная с позиции `pos - offset`).

Распакуй и выведи строку:

### Вход

```text
flag=0x80 lit=0x41    -> 'A'
flag=0x00 off=1 len=4 -> 'AAAA' (копия предыдущего 1 байт, 4 раза)
```

### Выход

```text
DECODED: AAAAA...
```

## Часть 2 — Кодирование

Реализуй жадный компрессор: для каждой позиции ищи в окне 4096 байт
самый длинный повтор (макс. длина 255). Если повтор ≥ 3 — выдай пару,
иначе литерал. Выведи поток флагов/байт как hex, и проверь
распаковкой:

```text
ROUNDTRIP OK (input=1234 output=1234)
```

## Подсказки

- Пересекающиеся копии (length > offset) обязаны работать — это
  стандарт для LZ77 (см. `lz4`/`deflate`).
- Жадный поиск O(n²) на окне 4096 — норм для тестов.
- Следи: offset не может быть больше числа уже распакованных байт.
