# Миссия 074 — Гонка дайверов

> Уровень: `★★★★☆` · Тема: гонки данных, критические секции

Гонка дайверов: несколько программ бегут к одной памяти наперегонки. Кто-то читает, кто-то пишет, и
результат зависит от того, кто успел первым.
— Гонки — это как очередь на перекрёстке, — Прах поправляет очки. — Без светофора выигрывает не тот,
кто прав, а тот, кто первый.
Джез учится ставить светофоры.

---

## Данные

- `data/074/runs.txt` — 10 записанных результатов «гонки»: 8 потоков по
  1_000_000 инкрементов общего счётчика без синхронизации;
- `data/074/fix.txt` — детерминированные времена трёх исправлений:
  `МЕТОД мс`.

## Часть 1 — Воспроизведение гонки

Найди минимум и максимум в `runs.txt`. Ожидаемое значение без гонки:
`8 × 1_000_000 = 8_000_000`:

```text
MIN=5221913 MAX=7999999 EXPECTED=8000000  (гонка!)
```

## Часть 2 — Фиксация

Три способа — мьютекс, атомарный инкремент, канал-аккумулятор — всегда
дают ровно `8_000_000`. Выведи их времена из `fix.txt`:

```text
LOCK: 8000000 in 214ms
ATOMIC: 8000000 in 31ms
CHAN: 8000000 in 198ms
```

## Подсказки

- Слова «гонка»: ищи `data race` (`go run -race`).
- Канал-аккумулятор: после `WaitGroup` просуммируй канал.
- Атомика обычно быстрее всего; мьютекс — понятнее всех.
