> Уровень: `★★★☆☆` · Тема: worker pool, параллелизм

Пул банкоматов: одна очередь на много машин, и ни одна не должна простаивать. Дон просит Джез написать диспетчер, который раздаёт работу.
— Работа — как дождь, — он смотрит в окно. — Её надо раздавать тем, кто успеет промокнуть первым.
Джез раздаёт дождь и учится не оставлять машины сухими.

## Часть 1 — Пул воркеров

Задачи: проверить PIN (перебор 0000–9999 против «заглушки»
`valid_pin(attempt)`), вычислить хэш задачи и т.п. Реализуй пул из
`W` воркеров: общая очередь задач, каждый берёт по одной, считает,
отдаёт результат. Без потерь и дублей.

Вход: `W`, число задач `N`, «сложность» задачи (мс). Выведи время
выполнения всего пула и в одиночку:

```
W=8  N=1000  T=134ms  (single=1020ms, speedup=7.6x)
```

## Часть 2 — Баланс нагрузки

Воркеры теперь «устают»: каждый следующий чанк задачи у воркера
занимает чуть больше времени (модель: `t * (1 + fatigue * n)`).
Сделай **динамическое** распределение: воркер берёт новую задачу,
как только освободился, а не статическими пачками.

Сравни статику (пачки по N/W) и динамику:

```
STATIC: 1432ms  DYNAMIC: 1210ms  (лучше: dynamic)
```

## Подсказки

- Очередь: канал (Go/Python `queue`) или семафор + общий счётчик.
- `speedup = single_time / pool_time`.
- «Усталость» — детерминированный параметр (`fatigue=0.1`), не
  случайность, чтобы тест был воспроизводим.
