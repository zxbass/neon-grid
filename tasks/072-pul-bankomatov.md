# Миссия 072 — Пул банкоматов

> Уровень: `★★★☆☆` · Тема: worker pool, параллелизм

Пул банкоматов: одна очередь на много машин, и ни одна не должна простаивать. Дон просит Джез
написать диспетчер, который раздаёт работу.
— Работа — как дождь, — он смотрит в окно. — Её надо раздавать тем, кто успеет промокнуть первым.
Джез раздаёт дождь и учится не оставлять машины сухими.

---

## Данные

`data/072/tasks.txt` — список задач: `id стоимость_мс`, по одной на
строку. Воркеров всегда `W=3`.

## Часть 1 — Пул воркеров

Симулируй пул из 3 воркеров: задачи разбираются из очереди по одной;
свободный воркер берёт следующую задачу (если освободились несколько —
берёт воркер с меньшим номером). Выведи время всего пула (момент, когда
закончил последний воркер), время в одиночку (сумма стоимостей) и
ускорение `single / pool` — один знак после запятой:

```text
W=3  N=10  T=100ms  (single=280ms, speedup=2.8x)
```

## Часть 2 — Статика против динамики

Статическое распределение: задачи режутся на последовательные пачки;
первые `N % W` воркеров получают `⌈N/W⌉` задач, остальные — `⌊N/W⌋`.
Каждый воркер считает свою пачку целиком. Динамическое — как в части 1.
Сравни времена:

```text
STATIC: 160ms  DYNAMIC: 100ms  (better: dynamic)
```

## Подсказки

- Очередь: канал или семафор + общий счётчик.
- `speedup = single_time / pool_time`.
- Симуляция должна быть чисто детерминированной: никаких таймеров.
