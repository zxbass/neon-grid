# Миссия 062 — Змейка «Кобра»

> Уровень: `★★★☆☆` · Тема: TUI-игра, симуляция по файлу ввода

Кобра-змейка — классика терминалов: точка растёт, грызёт себя и учится не кусать собственный хвост.
Дон говорит, что так выглядит почти вся жизнь в Сетке.
— Каждая программа — это змейка, — он смеётся. — Растёшь, пока не начнёшь мешать себе.
Джез пишет змейку и учится правилу, которое действует в Сетке везде: не кусай собственный хвост.

---

## Данные

- `data/062/test_keys.txt` — последовательность клавиш, по одной на строку
  (`w`/`a`/`s`/`d`);
- `data/062/food.txt` — очередь позиций еды, по одной `x y` на строку
  (колонка от 0 до 19, строка от 0 до 9).

## Часть 1 — Поле и змейка

Поле 20×10 (колонки 0..19, строки 0..9). Змейка длины 3 в центре: голова
в `(9,4)`, тело — влево, направление — вправо. Еда — клетка `@`.
При поедании — длина +1, следующая еда из файла.

Симуляция: максимум 200 тиков. В начале каждого тика читается следующая
клавиша из `test_keys.txt` (клавиш нет — направление не меняется;
разворот на 180° игнорируется). Затем голова двигается на 1 клетку:

- голова за пределами поля → `GAME OVER`;
- голова в теле (кроме хвоста, который в этом же тике уходит) →
  `GAME OVER`;
- голова на еде — съесть: счёт +1, хвост не убирается.

Отрисовка: 10 строк по 20 символов, `.` — пусто, `#` — тело, `H` — голова,
`@` — еда.

### Выход (финальное поле)

```text
@...................
....................
..............#####H
....................
....................
....................
....................
....................
....................
....................
```

## Часть 2 — Столкновения

После симуляции выведи результат:

```text
GAME OVER: score=N
```

или, если змейка прожила все 200 тиков:

```text
SURVIVED 200 ticks: score=N
```

### Выход

```text
GAME OVER: score=3
```

## Подсказки

- Храни змейку как список сегментов; движение — вставка головы +
  удаление хвоста (кроме случаев еды).
- Съеденную еду убирай с поля (`@` исчезает), следующую ставь из файла.
- Счёт и итог зависят только от файлов — без таймеров и RNG.
