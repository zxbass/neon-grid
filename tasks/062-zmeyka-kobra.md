# Миссия 062 — Змейка «Кобра»

> Уровень: `★★★☆☆` · Тема: TUI-игра, ввод без Enter

Кобра-змейка — классика терминалов: точка растёт, грызёт себя и учится не кусать собственный хвост.
Дон говорит, что так выглядит почти вся жизнь в Сетке.
— Каждая программа — это змейка, — он смеётся. — Растёшь, пока не начнёшь мешать себе.
Джез пишет змейку и учится правилу, которое действует в Сетке везде: не кусай собственный хвост.

---

## Часть 1 — Поле и змейка

Поле 20×10, змейка длины 3 в центре, движется раз в 150 мс. Ввод:
`w/a/s/d` (буфер между тиками: последняя нажатая клавиша побеждает).
Еда — случайная клетка (`@`). При поедании — длина +1, новое яблоко.

Отрисовка: очистка + сетка из `.`, змейка `#` (голова `H`), еда `@`,
счёт строкой сверху:

```text
SCORE: 5
....................
....H##.............
........@...........
```

## Часть 2 — Столкновения

Правила смерти: голова в стену или в тело → `GAME OVER`, показать счёт
и выйти. Вход для проверки — файл с последовательностью клавиш
(по одной на строку), а не клавиатура: `test_keys.txt`.

Тестовый сценарий: змейка идёт вправо, команды `sss` (повороты вниз),
пройти до еды, счёт ≥ 1, не умереть за 200 тиков:

### Выход

```text
GAME OVER: score=7
```

или, если не умер:

```text
SURVIVED 200 ticks: score=7
```

## Подсказки

- Клавиши без Enter: терминал в raw/cbreak режиме — `stty raw`, или
  используй библиотеку (curses/termios/tcell/readchar).
- Для теста достаточно файлового ввода: читай следующий символ, когда
  тик готов.
- Храни змейку как список сегментов; движение — вставка головы +
  удаление хвоста (кроме случаев еды).
