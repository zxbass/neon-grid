# Миссия 043 — HTTP вручную

> Уровень: `★★☆☆☆` · Тема: HTTP/1.1, сокеты

HTTP вручную — без библиотек, без каркасов: только ты, сокет и протокол. Зен требует, чтобы Джез
написала запрос буквами.
— Библиотеки — это чужие руки, — он пододвигает клавиатуру. — А в Сетке иногда нужно работать
своими.
Джез пишет. Сервер отвечает. Мир становится чуть более ручным.

---

## Данные

`data/043/response.txt` — сохранённый HTTP-ответ сервера: статус-строка,
заголовки и тело, разделённые `\r\n\r\n`. Строки заканчиваются `\r\n`.

## Часть 1 — Разбор ответа

Прочитай `response.txt` и разбери его вручную:

- статус: первая строка;
- заголовки: строки до пустой (`\r\n\r\n`), каждую — в нижнем регистре;
- тело: всё, что после пустой строки.

Выведи статус, заголовки и тело:

### Выход

```text
STATUS: 200 OK
HEADERS:
server: omegadyn/2.1
content-type: text/plain
content-length: 47
BODY:
MESSAGE FROM THE GRID: WE ARE MANY.
```

## Часть 2 — Проверка и флаг

Сверь, что ответ корректен: статус `200`, а длина тела совпадает с
`content-length`. Если всё сходится — выведи флаг задания:

### Выход

```text
FLAG: FLAG{HTTP_IS_OLD_SCHOOL}
```

## Подсказки

- Заголовки и тело разделяет двойной `\r\n` — не одиночный `\n`!
- Читай ответ байтами; тело — ровно `content-length` байт.
- Статус бери из первой строки: код и текст (`200 OK`), без
  `HTTP/1.1`.
