# Миссия 006 — Маска ICE

> Уровень: `★★☆☆☆` · Тема: битовые маски, флаги доступа

Сетка в этом квартале напоминает перекрёсток без светофоров: все едут, никто не смотрит по сторонам.
А на одном из узлов стоит ICE-маска, которая отсекает доступ по битовым флагам.
— Каждая защита — это список разрешённого, — CROW появляется из темноты за спиной Джез, как обычно,
бесшумно. — Покажи мне список — и я покажу тебе дверь.
Маска мигает тридцатью двумя битами, и в каждом бите кто-то что-то прячет.

## Часть 1 — Декодирование флагов

32-битное слово флагов, биты (нумерация от 0, младший):

| Бит | Право |
| ----- | ------- |
| 0 | READ |
| 1 | WRITE |
| 2 | TRACE |
| 3 | BREAK |
| 4 | INJECT |
| 5 | TUNNEL |
| 6 | SCAN |
| 7–31 | зарезервировано |

Для каждого слова выведи список включённых прав в порядке битов.

Вход: `00000013 00000202 00000020`

```text
00000013: READ WRITE BREAK
00000202: TRACE SCAN        (0x200 = бит 9? нет — 0x200 = бит 9 зарезервирован!)

Подожди. `0x13` = `0001 0011` → биты 0,1,4 → `READ WRITE INJECT`.
`0x202` = `0x200 | 0x002` → биты 1 и 9 → `WRITE` + зарезервированный
бит 9. Тренируйся считать в уме: `0x202 & (1<<1) != 0`, `0x202 & (1<<9) != 0`.

### Выход

```text
00000013: READ WRITE INJECT
00000202: WRITE bit9(reserved)

## Часть 2 — Генератор ключа

Чтобы пройти через шлюз, нужно слово, в котором включены РОВНО биты
`READ`, `TRACE` и `TUNNEL` и **выключены** все остальные. Найди такое
значение и выведи его в hex. Это ключ от «парадной двери» ICE.

### Ответ

```text
KEY: 0x25

(`0x25 = 0b100101` → биты 0,2,5 = READ TRACE TUNNEL.)

## Подсказки

- Используй `(word >> n) & 1` для проверки бита.
- Не мучай память: можно завести массив пар «бит→имя».
- В части 2 проверь, что НЕТ битов сверх нужных: `word & ~mask == 0`.
