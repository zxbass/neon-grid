# Миссия 115 — Руткит в образе

> Уровень: `★★★★★` · Тема: стелс, сокрытие в образах

Руткит в образе: система, которая прячет саму себя. Джез учится делать программы, которых не
существует.
— Лучший способ спрятать дерево — лес, — Прах кивает на список процессов. — А лучший способ спрятать
программу — система.
Джез прячет программу в системе.

---

## Часть 1 — Нарушение целостности

Образ `os.img` — последовательность страниц по 4096 байт. Для каждой
страницы посчитай SHA-256 и сравни с «чистым» списком хэшей
`hashlist.txt` (одна строка — один хэш). Найди страницы, которые
не совпали:

```text
DIRTY: page 0x0001 0x0200 0x0800  (3 pages)
```

## Часть 2 — Анатомия руткита

Подозрительная страница содержит код руткита:

- первые 4 байта — магия `RKT!`;
- байт 4 — размер встраиваемого модуля;
- дальше — модуль, XOR-зашифрованный ключом из байта 8 (ASCII).

Извлеки модуль, расшифруй, выведи строки (как в 101):

```text
MODULE: 512 bytes  key=K
STRINGS:
  /proc/sys/kernel/hostname
  dmesg
  hide_module
  pid 1
```

Определи, что делает руткит: он скрывает процесс с именем `bouncer`.
Выведи:

```text
ROOTKIT: hides process 'bouncer'
```

## Подсказки

- Хэши — из mission 028 (SHA-256 hex).
- Диапазон страниц: `len(образа)/4096`.
- Модуль после расшифровки — текст с инструкциями (их можно читать).
