# Миссия 097 — FSK-демодулятор

> Уровень: `★★★★☆` · Тема: FSK, демодуляция, биты

FSK-демодулятор: частота меняется, и в этом изменении — биты. Джез учится слушать не ноты, а их
переключения.
— Голос меняется, когда говорит правду, — Син говорит это так, будто знает о чём-то большем. —
Научись слышать переключения.
Джез слышит переключения.

---

## Часть 1 — Частоты и биты

Файл `fsk.wav`: 8000 Гц, 16-бит моно. Модуляция: марк `0` = 1200 Гц,
спейс `1` = 2400 Гц (как старый Bell 202). Каждый бит — 10 мс (80
семплов).

Для каждого бита определи частоту по нулевым пересечениям и выдай
`0`/`1`:

```text
BITS: 01101001...
```

## Часть 2 — Кадры

Биты группируются в кадр: байт `0x7E` (start flag), данные, `0x7E`
(end), всего 32 байта на кадр (старт/стоп входят). После последнего
бита может быть шум.

Декодируй данные между флагами. Они XOR с `0xA5` и затем развёрнуты:
`b = (b >> 4) | (b << 4)` (swap nibbles). Выведи:

```text
FRAME: TRANSMISSION_RECEIVED
```

и число кадров:

```text
FRAMES: 3
```

## Подсказки

- Порог частоты: 1800 Гц.
- Пересечения нуля за 80 семплов: при 1200 Гц ≈ 3.5 пары (округли),
  при 2400 ≈ 7.
- В начале/конце может быть «тишина» — определяй старт по флагу.
