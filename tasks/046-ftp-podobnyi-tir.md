# Миссия 046 — FTP-подобный «Тир»

> Уровень: `★★★☆☆` · Тема: сервер файлов, команды

Сервер, похожий на FTP-тир: команды, ответы, списки файлов. Настоящий полигон для тех, кто учится
говорить с машинами на их языке.
— Машины не обижаются, — Зен смотрит, как Джез шлёт команды. — Они отвечают. Вопрос — слышишь ли ты.
Джез слышит: сервер терпеливо перечисляет файлы, один за другим.

---

## Данные

`data/046/session.txt` — построчная запись FTP-подобной сессии:
команды `USER <имя>`, `LIST`, `GET <имя>` и ответы сервера
(`200 OK`, `200 END`, `n bytes`).

## Часть 1 — Протокол сессии

Прочитай `session.txt` и выбери строки:

- все `USER ...`, кроме `USER agent.ops`;
- все `GET ...` — в порядке появления.

### Выход

```text
USER crow -> 200 OK
GET boot.bin -> 512 bytes
GET vault.key -> 2048 bytes
```

## Часть 2 — Секретный пользователь

Файл `vault.key` выдаётся только операторам: их логин заканчивается на
`.ops`. Проверь сессию на присутствие такого входа и выведи его строку
`USER ...`:

### Выход

```text
USER agent.ops -> 200 OK
```

## Подсказки

- Строка команды начинается с `USER`/`LIST`/`GET` — ответы сервера
  (`200 ...`, имена файлов) не входят в вывод.
- Порядок строк в части 1 — порядок появления в файле.
- Если строк нужного вида нет — выводи пустую строку.
