# Миссия 046 — FTP-подобный «Тир»

> Уровень: `★★★☆☆` · Тема: сервер файлов, команды

Сервер, похожий на FTP-тир: команды, ответы, списки файлов. Настоящий полигон для тех, кто учится
говорить с машинами на их языке.
— Машины не обижаются, — Зен смотрит, как Джез шлёт команды. — Они отвечают. Вопрос — слышишь ли ты.
Джез слышит: сервер терпеливо перечисляет файлы, один за другим.

---

## Часть 1 — Клиент

Протокол построчный. Команды:

- `USER <имя>` → `200 OK` / `401 DENIED`
- `LIST` → список `ИМЯ\tРАЗМЕР\n`, затем `200 END`
- `GET <имя>` → `200 SIZE=<n>\n` + ровно `n` байт данных + `\n`
- `QUIT` → `200 BYE`, сервер закрывает.

Клиент: подключается, шлёт `USER crow`, `LIST`, выводит список, затем
`GET` всех файлов по очереди, сохраняя каждый в `download/<имя>`.

### Выход

```text
USER crow -> 200 OK
LIST: boot.bin  512
      map.raw   4096
GET boot.bin -> 512 bytes

## Часть 2 — Секретный файл

Файл `vault.key` выдаётся только если имя пользователя заканчивается
на `.ops` (например `agent.ops`). Ответ на `GET vault.key` для обычного
пользователя — `403 FORBIDDEN`. Запусти клиент с двух имён и покажи,
что для `agent.ops` файл скачался:

### Выход

```text
USER crow -> 200 OK
GET vault.key -> 403 FORBIDDEN
USER agent.ops -> 200 OK
GET vault.key -> 2048 bytes

## Подсказки

- Размер в `200 SIZE=` — это **байты**, а не строки: читай ровно n.
- Строки заканчиваются `\r\n` — не путай с обычным `\n`.
- После данных данных сервер шлёт пустую строку — прочитай и пропусти.
