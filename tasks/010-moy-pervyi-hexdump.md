# Миссия 010 — Мой первый hexdump

> Уровень: `★★☆☆☆` · Тема: утилита hexdump, вывод

В лог «Гаража» свалили дамп чужой переписки, где одни и те же строки повторяются сотнями раз. CROW
заплатил за него половиной тарифа и теперь требует, чтобы Джез вычистила дубликаты.
— Шум не продаётся, — он стучит по экрану. — Продаётся только то, что отличается от всего
остального.
Джез выводит дамп на экран и впервые видит: в повторении тоже есть ритм. Ритм, под который кто-то
прячет сигнал.

---

## Часть 1 — Полный дамп с группами

Вывод по 16 байт, байты сгруппированы по 4 (между группами — один
пробел, внутри группы hex без пробелов):

```text
00000000  4e454f4e 47524944 312e3000 00000000  |NEONGRID1.0.....|
00000010  414c4c4f 592d3636 00000000 00000000  |ALLOY-66........|
```

То есть группы по 4 байта, слева hex без пробелов внутри группы,
между группами — один пробел.

## Часть 2 — Режим отличий

Флаг `-d`: если следующая строка идентична предыдущей, выведи `*` на
отдельной строке и продолжай с первой отличающейся. Флаг `-c`: только
колонку ASCII без hex. Флаги можно комбинировать (`-dc`).

### Пример

```text
00000000  4e454f4e 47524944 312e3000 00000000  |NEONGRID1.0.....|
*
00000020  4e454f4e 47524944 322e3000 00000000  |NEONGRID2.0.....|
```

## Подсказки

- Читай файл байтами (или блоками), веди счётчик смещения.
- Группировка по 4: разбей 16 байт на 4 группы по 4.
- Строки короче 16 байт: дополняй hex-часть пробелами до нужной длины,
  чтобы `|ascii|` стоял на месте.
- Для `-d` держи предыдущую строку в памяти; «идентичная» = полностью
  равная (адрес игнорируй).
