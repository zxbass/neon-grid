# Миссия 042 — Эхо «Зен»

> Уровень: `★☆☆☆☆` · Тема: TCP-сервер, echo

На одной из точек Сетки работает сервис, который отвечает ровно тем, что ему послали, — эхо. Зен
говорит, что эхо — лучший учитель: оно не врёт.
— Пошли мусор — получишь мусор, — он пожимает плечами. — Пошли порядок — и мир вокруг станет
упорядоченным.
Джез шлёт эху первый запрос и получает его обратно. Целым.

---

## Часть 1 — Эхо-сервер

Напиши TCP-сервер на порту (аргумент). На каждое подключение: читай
строки, пока не получишь `\n` (или `\r\n`), отправляй обратно **ту же**
строку. Когда клиент шлёт `QUIT\n` — закрывай соединение. Слушай
следующих клиентов.

### Входные данные

Сам себя проверишь клиентом:

```bash
echo "ping"   -> pong? нет — сервер вернёт "ping"

### Выход

```text
[server] connection from 127.0.0.1:54321

## Часть 2 — Клиент и счётчик

Клиент подключается, шлёт `HELLO <имя>\n`, получает эхо, шлёт `BYE\n`,
закрывает соединение. Сервер логирует каждый обмен в файл
`echo.log` строкой `TIME ip:port -> "сообщение"`.

Проверка: `echo.log` содержит все строки в порядке обмена.

### Пример echo.log

```text
12:01:22 127.0.0.1:54321 -> "HELLO crow"
12:01:22 127.0.0.1:54321 -> "BYE"

## Подсказки

- Читай построчно с буфером: `bufio.Reader.ReadString('\n')` / Python
  `sock.makefile()`.
- Порт держи маленький: 1200 (Зен любит эту частоту).
- Обрабатывай ошибку «порт занят» — выведи `PORT BUSY` и выйди.
