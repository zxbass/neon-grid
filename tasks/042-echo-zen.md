# Миссия 042 — Эхо «Зен»

> Уровень: `★☆☆☆☆` · Тема: TCP-сервер, echo

На одной из точек Сетки работает сервис, который отвечает ровно тем, что ему послали, — эхо. Зен
говорит, что эхо — лучший учитель: оно не врёт.
— Пошли мусор — получишь мусор, — он пожимает плечами. — Пошли порядок — и мир вокруг станет
упорядоченным.
Джез шлёт эху первый запрос и получает его обратно. Целым.

---

## Данные

`data/042/echo.log` — журнал эхо-сервера. Каждая строка — один обмен:
`TIME ip:port -> "сообщение"`. Пять строк, два разных клиента.

## Часть 1 — Счётчик обменов

Прочитай `echo.log` и посчитай:

- `CONNECTIONS` — сколько разных `ip:port` встречается в журнале;
- `EXCHANGES` — сколько всего строк (обменов);
- `LAST` — последняя строка журнала целиком.

### Выход

```text
CONNECTIONS: 2
EXCHANGES: 5
LAST: 12:01:26 127.0.0.1:54322 -> "BYE"
```

## Часть 2 — Журнал

Проверка целостности: выведи все строки `echo.log` в исходном порядке —
журнал не должен потерять ни одного обмена.

### Выход

```text
12:01:22 127.0.0.1:54321 -> "HELLO crow"
12:01:22 127.0.0.1:54321 -> "BYE"
12:01:25 127.0.0.1:54322 -> "HELLO zen"
12:01:25 127.0.0.1:54322 -> "ping"
12:01:26 127.0.0.1:54322 -> "BYE"
```

## Подсказки

- Читай построчно с буфером: `bufio.Scanner` / Python `readlines()`.
- `CONNECTIONS` считай по уникальным `ip:port` — клиент считается одним
  подключением, даже если прислал несколько сообщений.
- Строки выводи без лишних переводов строк на конце.
