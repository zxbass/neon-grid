# 153 — PLT/GOT: ленивая привязка

> Уровень: `★★★★☆` · Тема: PLT/GOT · динамическая линковка

PLT/GOT: таблицы, через которые программы вызывают чужие функции. Джез видит, как ленивая привязка откладывает работу до последнего — и понимает, что лень — это тоже архитектура.
— Дорогу осилит идущий, — Зен поправляет очки. — А программа — только тот, кого позвали.
Джез узнаёт, кого зовут.

---

## Данные
- `data/153/got.txt` — строки `имя SLOT=0x... VALUE=0x... STUB=0x... SYM=0x...`

## Часть 1
Для каждой функции верни фактический адрес после резолвинга: `имя -> 0x%08X` (если VALUE == STUB — бери SYM, иначе VALUE).

## Часть 2
Верни `GOT[имя]=0x%08X` для всех трёх функций.
