# Миссия 111 — Мультихоп через ICE

> Уровень: `★★★★☆` · Тема: обход ICE, цепочки маршрутов

Мультихоп через ICE: ледяная стена из нескольких слоёв, и через каждый нужно пройти своим ключом.
Джез впервые идёт сквозь лёд.
— Лёд — это стена, которая думает, — Прах говорит это со знанием дела. — Но и стена устаёт думать.
Джез идёт сквозь уставшую стену.

---

## Часть 1 — Граф контуров

Карта — файл `ice_map.txt`:

```text
NODE  NAME        TYPE   INPUTS
0     GATE        tcp    -
1     LOBBY       udp    0
2     VAULT       tcp    1
3     CORE        icmp   2
```

Контур `TYPE` принимает пакеты только своего типа. Тип пакета можно
сменить в контуре (поле `OUTPUT`). Найди путь из `GATE` (0) в `CORE`
(3), перечисляя типы:

```text
PATH: 0(tcp) -> 1(udp) -> 2(tcp) -> 3(icmp)
```

## Часть 2 — Ловушки

Контуры могут содержать «ловушки»: если тип не совпадает — `TRACED`
(путь умирает). Но есть приём: «пакет-призрак» — контур с полем
`GHOST` пропускает **любой** тип, но замедляет на 1 хоп (цена пути).

Карта с ценами. Найди кратчайший путь (BFS/Dijkstra) с учётом
штрафов GHOST=2:

```text
PATH: 0 -> 1(ghost) -> 4 -> 3  (cost=4)
ALTERNATIVE: 0 -> 2 -> 3 (cost=5)
```

## Подсказки

- BFS по графу, состояние = (узел, тип пакета).
- GHOST удваивает стоимость перехода.
- Если путь не найден — `NO ROUTE` (и проверь, не в ловушке ли вся карта).
