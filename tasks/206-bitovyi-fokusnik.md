# 206 — Битовый фокусник

> Уровень: `★★★☆☆` · Тема: math/bits · битовые операции

CROW прислал ключи без объяснений — только «посчитай». Джез смотрит на нули и единицы и понимает,
что каждый бит — это отдельная монета.
— Бит — это не часть числа, — Зен щёлкает выключателем. — Это сам выключатель.
Джез учится щёлкать.

---

## Данные

- `data/206/values.bin` — 8 значений `uint32` в little-endian

## Часть 1

Для каждого значения выведи число установленных бит (popcount):
`0x%08X -> %d`.

## Часть 2

Для каждого значения выведи реверс бит (зеркально, 32 бита):
`0x%08X -> 0x%08X`.
