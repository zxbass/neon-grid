# 145 — Wasm-контейнер

> Уровень: `★★★★★` · Тема: WebAssembly · модули

WebAssembly-модуль, который никто не запускал: контейнер с функциями внутри. Джез учится читать
модуль, как корабельный журнал — секция за секцией.
— Модуль — это корабль, — Зен кивает на байты. — Секции — его трюмы. Загляни в трюм — узнаешь груз.
Джез заглядывает в трюмы.

---

## Данные

- `data/145/mod.wasm`

## Часть 1

Верни `SECTIONS: TYPE FUNC EXPORT CODE` — id секций в порядке файла.

## Часть 2

Верни `EXPORT: zen FUNC 0` (из секции экспортов) и `BODY BYTES: 3` — размер тела функции (код без
счётчика locals).
