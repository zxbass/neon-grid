# Миссия 110 — Распаковка «Целлофан»

> Уровень: `★★★★★` · Тема: unpacking, стриппер, self-decoding

Распаковка целлофана: упакованная программа, которая сначала распаковывает себя, потом работает. Джез учится снимать обёртку, не повредив содержимое.
— Упаковка — это чемодан, — Зен ставит перед Джез коробку. — Открой аккуратно — и увидишь, что везли.
Джез открывает чемодан.

---

## Часть 1 — Распаковщик

Файл `packed.bin` — 64 КБ, структура:

| Смещение | Размер | Поле |
|----------|--------|------|
| 0 | 4 | магия `PKUP` |
| 4 | 4 | размер распакованного (u32 LE) |
| 8 | 4 | offset кода-распаковщика (u32 LE) |
| 12 | 16 | ключ (ASCII, до NUL) |
| 28 | ... | зашифрованные данные |

Распаковка: данные XOR с повторяющимся ключом (как в 021), затем
собираются в `unpacked.bin` размером из заголовка.

Выведи магию, размер и распакуй:

```
PKUP size=32768 key=CELLOPHANE
UNPACKED: 32768 bytes
```

## Часть 2 — Внутренности

В распакованном коде лежит «VM-программа» из 107. Декомпилируй её
и найди, какое значение она вычисляет для `x0 = 7` (входные данные —
переменная x0 перед началом):

```
x1 = x0 * 3 + 4
RESULT(7) = 25
```

Сверь: при запуске через эмулятор из 109 результат совпадает.

## Подсказки

- XOR-ключ может быть короче данных — повторяй по кругу (миссия 021).
- Проверяй, что распакованный размер ≥ 0 и ≤ 16 МБ.
- Декомпилятор из 107 переиспользуй как есть.
