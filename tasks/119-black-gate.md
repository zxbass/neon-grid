BLACK_GATE: чёрные врата, за которыми кто-то живёт. Джез впервые стоит перед дверью, которую нельзя
открыть силой.
— Врата — это вопрос, — МЕРКУРИЙ произносит это медленно. — А ответ на него — вся твоя история.
Джез собирает свою историю в ответ.

## Часть 1 — Пять слоёв

`black_gate.bin` — образ шлюза, слои идут последовательно:

1. **Слой 1** — 4 байта, поле `version` (u32 LE). Должно быть `>= 7`.
2. **Слой 2** — 256 байт XOR с ключом из байта 4 образа; внутри — 16-бит
   длина `L` (u16 LE) и данные. Расшифруй (миссия 021).
3. **Слой 3** — данные из слоя 2 (длина `L`) — RLE-распаковать
   (миссия 032), внутри — пароль `AUTH <pw>`.
4. **Слой 4** — пароль проверить: он должен валиться через CRC16 из
   016 равным 0x5A5A.
5. **Слой 5** — на «экране» TUI (060) появляется код доступа.

Выполни все слои и выведи прохождение:

```text
LAYER 1: OK (version=9)
LAYER 2: decrypted (len=512)
LAYER 3: unpacked (password=GATEKEEPER)
LAYER 4: crc OK
LAYER 5: ACCESS GRANTED
