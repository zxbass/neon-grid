## Часть 1 — Longest Prefix Match

Для каждого `lookup:` выбери самый длинный префикс, покрывающий адрес,
и выведи его next hop.

### Выход

```text
10.1.2.44 -> 3.3.3.3
10.5.1.1 -> 1.1.1.1
8.8.8.8 -> 9.9.9.9
```

## Часть 2 — Forwarding-симуляция

Пакет отправляется из SRC в DST: на каждом узле выбирается следующий
по графу, пока пакет не достигнет DST. Выведи кратчайший путь (BFS,
соседи в порядке списка) и число хопов. Если DST недостижим —
`LOOP DETECTED`.

### Выход

```text
PATH: R1 -> R3 -> R5 -> R7 (3 hops)
LOOP DETECTED
```

## Подсказки

- Маска: `(addr & mask) == (net & mask)`;
  `mask = (~0 << (32 - len)) & 0xFFFFFFFF`.
- LPM: сравнивай длины префиксов; маршрут по умолчанию (`/0`)
  покрывает всё.
- Второй запрос ведёт в несуществующий узел — предел хопов 64.
