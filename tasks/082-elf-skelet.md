## Часть 1 — Заголовок

ELF-заголовок (64-бит):

| Смещение | Поле |
| ---------- | ------ |
| 0 | `\x7fELF` |
| 4 | класс (2 = ELF64) |
| 5 | порядок байт (1 = LE) |
| 18 | тип (3 = ET_DYN) |
| 20 | машинный тип (62 = x86-64) |
| 24 | entry (u64) |
| 40 | offset program header table (u64) |
| 52 | offset section header table (u64) |
| 58 | число section headers (u16) |
| 60 | индекс секции имён (u16) |

Выведи:

```text
ELF64 LE  type=ET_DYN  machine=x86-64  entry=0x401000  shdr=13

## Часть 2 — Секции

Каждая section header — 64 байта: имя (offset в strtab), type,
flags, addr, offset, size и т.д. Найди секцию `.rodata` (имена через
strtab) и выведи её содержимое как строки (печатные ASCII, до 512 байт):

```text
SECTION .rodata (offset=0x2000 size=0x80)
FLAG: crow_was_here_2049

Также найди `.text` и выведи entry-инструкцию (первые 8 байт в hex):

```text
.text entry bytes: 48 8b 05 00 00 00 00 00

## Подсказки

- Все офсеты u64 для ELF64 — читай с точностью.
- Имя секции: `strtab_offset + sh_name`.
- `e_shstrndx` — индекс секции `.shstrtab` в таблице.
- `sh_addr` может быть 0 для секций без загрузки (тогда используй
  `sh_offset`).
