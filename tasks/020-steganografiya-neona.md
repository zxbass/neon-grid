# Миссия 020 — Стеганография «Неона»

> Уровень: `★★★★☆` · Тема: LSB-стеганография, битовые манипуляции

Рекламный баннер на углу показывал одну и ту же картинку месяц, пока кто-то не заметил, что она чуть-чуть другая. В битах младшего разряда спрятано сообщение, и Крем уже три дня ходит вокруг баннера кругами.
— Самое надёжное место — то, которое все видят, — говорит он, кивая на экран. — Никто не смотрит на то, что бросается в глаза.
Джез извлекает биты из пикселей, и на фоне рекламы проступает адрес. Адрес, по которому лучше идти ночью.

---

## Часть 1 — LSB-извлечение

Файл `carrier.bmp` — 24-бит BMP без палитры, ширина кратна 8.
Каждый пиксель — B,G,R. Биты сообщения лежат в младших битах каналов
в порядке: сначала R канал первого пикселя, потом G, потом B.

Собирай биты в байты (MSB-first внутри байта). Длина сообщения в байтах
записана в первых 4 байтах как u32 LE (сообщение — 4 байта длины +
данные). Извлеки и выведи строку.

### Выход

```
PAYLOAD: MEET_AT_NEON_ALLEY_3AM
```

## Часть 2 — Сокрытие

Теперь спрячь своё сообщение: файл `host.bmp`, сообщение задаётся
аргументом. Запиши младшие биты (длина u32 LE + данные) в каналы
B,G,R каждого пикселя. Сохрани копию как `stego.bmp`. Проверь: после
сокрытия файл должен остаться валидным BMP с теми же размерами.

### Выход

```
WROTE stego.bmp (ok, 120x90)
```

## Подсказки

- Индекс пикселя `p`, канал `c`: позиция в потоке `p*3 + c` (B=0,G=1,R=2).
- Для извлечения: `(channel & 1) << (7 - (pos % 8))`.
- Для встраивания: `channel = (channel & 0xFE) | bit`.
- Обязательно проверь, что `len(payload) * 8 ≤ width*height*3`.
