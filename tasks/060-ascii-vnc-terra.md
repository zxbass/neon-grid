# Миссия 060 — ASCII-VNC «Терра»

> Уровень: `★★★★☆` · Тема: удалённый экран, протоколы

ASCII-VNC: удалённый экран, нарисованный символами. Джез смотрит на чужой терминал и впервые видит,
как работает другой человек, — по буквам его экрана.
— Экран — это лицо, — Син смотрит на символьный шум. — Даже если лицо нарисовано точками.
Джез читает чужое лицо, составленное из точек и решёток.

---

## Часть 1 — Протокол экрана

Сервер шлёт кадры:

```text
0x01 | rows(u16 BE) | cols(u16 BE) | data(rows*cols байт, каждый — код символа ASCII 32..126)

Вьювер рисует кадр в терминал (очистка + вывод). Вход — бинарный файл
`screen.dump` с несколькими кадрами. Выведи только последний кадр
(все предыдущие — просто перерисовки).

### Выход

```text
GATEWAY 12 // SYSTEM READY
UNAUTHORIZED ACCESS IS FELONY
> _

## Часть 2 — Клавиши и диффы

Клиент отправляет нажатия как `0x02 | key(u8)` (key — код ASCII).
Сервер может отвечать **инкрементальными** кадрами: `0x03 | row(u16 BE)
| col(u16 BE) | data(...)` — только изменённые строки.

Реализуй клиент, который: подключается, шлёт клавиши `A`, `B`, `C`
(с паузой 100 мс), собирает финальный экран из полных и
инкрементальных кадров и выводит его:

### Выход

```text
> ABC_

## Подсказки

- «Очистка + вывод» = `\x1b[2J` + `\x1b[H` (ANSI).
- Инкрементальный кадр обновляет только строку `row`, начиная с `col`.
- Для теста без сервера прочитай `screen.dump`, потом сгенерируй
  дифф-кадры сам и проверь сборку.
