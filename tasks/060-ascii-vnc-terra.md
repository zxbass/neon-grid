# Миссия 060 — ASCII-VNC «Терра»

> Уровень: `★★★★☆` · Тема: удалённый экран, протоколы

ASCII-VNC: удалённый экран, нарисованный символами. Джез смотрит на чужой терминал и впервые видит,
как работает другой человек, — по буквам его экрана.
— Экран — это лицо, — Син смотрит на символьный шум. — Даже если лицо нарисовано точками.
Джез читает чужое лицо, составленное из точек и решёток.

---

## Данные

Файл `data/060/screen.dump` — запись сессии удалённого экрана 3×30.
Записи:

- `0x01 | rows(u16 BE) | cols(u16 BE) | data(rows*cols)` — полный кадр
  (каждый байт — код символа ASCII 32..126, строки дополнены пробелами);
- `0x02 | key(u8)` — нажатие клавиши клиента;
- `0x03 | row(u16 BE) | col(u16 BE) | data` — инкрементальный кадр:
  перезаписывает строку `row`, начиная с `col`.

## Часть 1 — Последний полный кадр

Прочитай файл и выведи содержимое последнего полного кадра (`0x01`),
по строке на экранную строку, обрезав хвостовые пробелы.

### Выход

```text
GATEWAY 12 // SYSTEM READY
UNAUTHORIZED ACCESS IS FELONY
> ABC_
```

## Часть 2 — Применение диффов

Возьми последний полный кадр и примени к нему все инкрементальные
кадры (`0x03`), идущие после него. Выведи финальный экран.

### Выход

```text
GATEWAY 42 // SYSTEM READY
UNAUTHORIZED ACCESS IS FELONY
> ABC_
```

## Подсказки

- Нажатия клавиш (`0x02`) на экран не влияют — пропусти их.
- Дифф перезаписывает строку от `col` до конца своих данных;
  остальное в строке не меняется.
- Финальные строки обрезай по хвостовым пробелам.
