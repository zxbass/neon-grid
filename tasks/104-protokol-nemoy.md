# Миссия 104 — Протокол «Немой»

> Уровень: `★★★★☆` · Тема: реверс протокола

Немой протокол: устройство, которое отвечает только тогда, когда знает пароль. Джез учится молчать
вместе с ним и ждать.
— Иногда лучшее, что можно сделать, — это не говорить, — CROW поднимает палец. — А слушать, как
молчит собеседник.
Джез слушает чужое молчание.

---

## Данные

- `data/104/protocol.txt` — словарь фаззера: строки `КОМАНДА [аргументы] -> ОТВЕТ`.
  Ответ `?` означает, что команда «мертва» (сервер её не знает).

## Часть 1 — Нащупывание

Прочитай `protocol.txt` построчно. Для каждой строки, у которой ответ не `?`,
выведи имя команды (первое слово) и ответ:

- формат: `cmd + ":"` выравнивается влево до 5 символов (`%-5s`),
  затем пробел и ответ.

### Выход

```text
AUTH: OK crow
LOGIN: DENY
PING: PONG 1234
GET:  ERR_NEED_KEY
```

## Часть 2 — Полный хендшейк

Протокол знает три рабочих шага:

1. `AUTH crow` → `OK crow`;
2. после `OK` сервер ждёт `KEY <токен>`, где токен = первые 8 символов
   `hex(sha256("OMEGA:crow"))`;
3. после ключа `GET flag` отдаёт флаг.

Вычисли токен и выведи весь хендшейк строками `команда -> ответ`:

### Выход

```text
AUTH crow -> OK crow
KEY eb05911e -> ACCEPTED
GET flag -> FLAG{MUTE_PROTOCOL_BROKEN}
```

## Подсказки

- SHA-256 с префиксом `OMEGA:` — как в 028.
- Ответы `AUTH crow` и `GET flag` бери из `protocol.txt`.
