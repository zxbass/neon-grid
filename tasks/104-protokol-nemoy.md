# Миссия 104 — Протокол «Немой»

> Уровень: `★★★★☆` · Тема: реверс протокола

Немой протокол: устройство, которое отвечает только тогда, когда знает пароль. Джез учится молчать вместе с ним и ждать.
— Иногда лучшее, что можно сделать, — это не говорить, — CROW поднимает палец. — А слушать, как молчит собеседник.
Джез слушает чужое молчание.

---

## Часть 1 — Нащупывание

Сервер на 1200. Эксперименты:

- отправка `\n` → ответ `?\n`;
- `AUTH <имя>\n` → `OK <имя>\n` или `DENY\n`;
- `PING <n>\n` → `PONG <n>\n`;
- неизвестное → `?\n`.

Напиши «фаззер», который пробует команды по словарю
(`AUTH`, `LOGIN`, `PING`, `ECHO`, `GET`, `TIME`, `HELP`) и выводит
ответы. Выведи найденные работающие команды:

```
AUTH: OK crow
PING: PONG 1234
GET:  ERR_NEED_KEY
```

## Часть 2 — Полный хендшейк

Методом перебора найди полную последовательность:

1. `AUTH crow` → `OK crow`;
2. после `OK` сервер ждёт `KEY <токен>`, где токен = `hex(sha256("OMEGA:" + имя))` первые 8 символов;
3. после ключа — `GET flag` работает.

Реализуй клиент, который сам считает токен и забирает флаг:

```
AUTH crow -> OK crow
KEY 1a2b3c4d -> ACCEPTED
GET flag -> FLAG{MUTE_PROTOCOL_BROKEN}
```

## Подсказки

- Читай ответы до перевода строки, тайм-аут 500 мс.
- Словарь фаззера расширь найденным (команды из ответов на ошибки).
- SHA-256 с префиксом `OMEGA:` — как в 028.
