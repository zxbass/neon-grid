# Миссия 114 — Прокси через корпсеть

> Уровень: `★★★★★` · Тема: туннель поверх HTTP, энкапсуляция

Прокси через корпоративную сеть: спрятаться за чужим щитом, чтобы никто не видел, откуда ты идёшь.
Джез учится быть тенью за чужой спиной.
— Прокси — это зонтик, — CROW выдыхает дым. — В дождь идти удобнее, но зонтик запоминает, кто под
ним стоял.
Джез учится не оставлять мокрых следов.

---

## Данные

- `data/114/frames.bin` — захваченные кадры туннеля:
  - `0x01` + длина u16 (BE) + данные — кадр данных;
  - `0x02` — конец потока.

## Часть 1 — HTTP-клиент-туннель

Разбери `frames.bin` на кадры. Данные разбиты на 5 блоков (последний
может быть короче). Посчитай блоки — каждый блок «ушёл» в туннель
и вернулся зеркально:

### Выход

```text
SENT 5 blocks  RECEIVED 5 blocks
MIRROR OK
```

## Часть 2 — Полный дуплекс

Склей данные всех кадров данных в одно сообщение и выведи его вместе
с итогом (число кадров данных):

### Выход

```text
HELLO GRID, TUNNEL ECHO 5 BLOCKS OK
TUNNEL OVER HTTP: OK (5 frames)
```

## Подсказки

- Кадр: байт типа, затем длина (big-endian), затем данные.
- `0x02` — признак конца: дальше кадров нет.
