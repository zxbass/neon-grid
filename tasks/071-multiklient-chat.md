# Миссия 071 — Мультиклиент-чат

> Уровень: `★★★☆☆` · Тема: параллельные подключения, broadcast

Мультиклиент-чат: много голосов, один канал. Джез впервые пишет программу, которая слушает всех
сразу, и слышит, как в одном потоке живут десятки людей.
— Каждый клиент — это дверь, — Зен кивает на окна чата. — Открой их все — и увидишь, как тесно в
квартале.
Джез открывает все двери и впервые чувствует пульс толпы.

---

## Данные

`data/071/chat.log` — детерминированная запись сессии. Строки двух видов:

- `HH:MM:SS CONNECT имя` — клиент подключился;
- `HH:MM:SS [имя] текст` — сообщение клиента.

## Часть 1 — Статистика сессии

Посчитай по транскрипту: сколько клиентов подключилось, сколько
сообщений отправлено и сколько доставок выполнил сервер. Каждое
сообщение доставляется всем остальным клиентам:

`доставки = сообщения × (клиенты − 1)`.

```text
CONNECTIONS: 3  MESSAGES: 7  DELIVERED: 14
```

## Часть 2 — Синхронный лог

Лог пишется одним блоком: только сообщения (без временных меток и
строк CONNECT). Выведи число строк лога и первое сообщение:

```text
LOG: 7 lines, first: [crow] ready
```

## Подсказки

- Мьютекс на списке клиентов и на буфере сообщений — классика чата.
- Broadcast не должен ронять сервер при отключении клиента посреди
  цикла.
- Счётчик доставок обязателен: без него тест упадёт.
