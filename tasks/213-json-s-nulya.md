# 213 — JSON с нуля

> Уровень: `★★★★☆` · Тема: парсер · JSON

Конфиг шлюза Омега-Дайн написан на JSON, а библиотекам Синдикат не доверяет. Джез пишет свой
парсер — вложенные объекты, массивы, строки, числа и булевы значения.
— Чужой парсер — чужой замысел, — Прах проверяет скобки. — Свой видишь насквозь.
Джез видит насквозь.

---

## Данные

- `data/213/config.json` — конфигурация сервера

## Часть 1

Верни значения полей: `NAME: <имя>`, `PORT: <порт>`, `DEBUG: <true|false>`
(из `server.name`, `server.port`, `server.debug`).

## Часть 2

Верни `KEYS: <n>` (число всех ключей во всех объектах, включая вложенные),
`MAX_DEPTH: <n>` (глубина вложенности объектов, корень = 1) и
`STRINGS: <n>` (число строковых значений, включая элементы массивов).

Не используй `encoding/json` — напиши разбор вручную.
