# 211 — Эллиптическая точка

> Уровень: `★★★★★` · Тема: ECDH · эллиптические кривые

Контракты CROW закончились — началась своя игра. «Стеклянные дворцы» Омега-Дайн держат связь на
эллиптических кривых: маленькая точка вместо большого числа.
— Ключ — это точка на кривой, — Прах чертит на пыльном стекле. — Умножь её на своё число — получишь
своё. Сложи чужие — получите общее.
Джез учится складывать точки.

## Данные

- `data/211/curve.txt` — параметры кривой `y² = x³ + ax + b (mod p)`, базовая точка
  `G`, её порядок, `alice_priv`, `bob_priv` и публичный ключ Боба `pub_b`

## Часть 1

Вычисли публичный ключ Алисы: `PUB_A: (x, y)` — это `alice_priv · G`.

## Часть 2

Вычисли общий секрет: `SHARED: (x, y)` — это `alice_priv · pub_b`
(он же `bob_priv · pub_a`).

Сложение точек: `P+Q` через наклон `λ = (y₂−y₁)/(x₂−x₁)`, удвоение —
`λ = (3x²+a)/(2y)`; всё по модулю `p`, деление — обратный элемент
(`a^(p−2) mod p`). Точка на бесконечности — нейтральный элемент.
