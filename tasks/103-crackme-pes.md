# Миссия 103 — Crackme «Пёс»

> Уровень: `★★★★☆` · Тема: crackme, поиск пароля

Crackme-пёс: маленькая программа, которая проверяет пароль. Джез должна понять, как она думает, и
сказать ей правильное слово.
— Проверка пароля — это вопрос, — Зен откидывается в кресле. — Ответь правильно — и дверь откроется
сама.
Джез учится отвечать на чужие вопросы.

---

## Часть 1 — Алгоритм

Программа проверки `check(pw: String) -> bool` (приведена ниже, не
бинарник!):

```python
def check(pw):
    if len(pw) != 8: return False
    v = 0x5A5A5A5A
    for i, c in enumerate(pw):
        v = rotl32(v ^ (ord(c) << (i * 3)), 7)
    return v == 0xCAFEBABE
```

(rotl32 — поворот влево на 7, как в 009.)

Пароль ровно 8 символов, все — печатные ASCII (32–126). Перебери
в разумной стратегии (или реверсируй). Выведи:

```text
PASSWORD: x?y?z?  (посчитай)
```

## Часть 2 — Формальная инверсия

Алгоритм обратим: начни с `0xCAFEBABE` и иди **назад** — обратные
операции: `rotr32` на 7 и XOR. Для каждого шага получи байт, но из-за
сдвига `<< (i*3)` байт может «перекрываться» соседями — используй
маски:

- шаг i: `v_prev = rotr32(v, 7) ^ (c << (i*3))`;
- байт c (печатаемый) подбери так, чтобы `v_prev & 0xFF` (со смещением
  `i*3`) дал согласованный результат с предыдущим шагом.

Это классическая «подстановка»: найди 8 символов за конечное число
проб (не 94^8, а ~8×256). Выведи пароль и подтверди `check == true`:

```text
PASSWORD: 390M38aZ
CHECK: true
```

## Подсказки

- `rotr32(x,7) = (x >> 7) | (x << 25)`.
- Для части 1 можно перебор 94^8 не потянуть — используй инверсию
  из части 2, она и есть «правильное» решение.
- Символы 32..126: отсекай непечатные кандидаты.
