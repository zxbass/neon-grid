# Миссия 052 — Эхо ICMP

> Уровень: `★★★★☆` · Тема: ICMP, контрольные суммы

ICMP-эхо — как эхо в горах: послал сигнал — вернулся. Но в горах Сетки эхо иногда возвращается не с
тем лицом.
— Проверь, что отвечает, — Зен откидывается в кресле. — А потом — кто отвечает.
Джез собирает эхо-запрос и сверяет контрольные суммы ответа, чтобы понять, настоящее ли это эхо.

---

## Данные

- `data/052/input.txt` — параметры запроса:
  `type=8 code=0 id=0x1234 seq=0x0001 data=hello`
- `data/052/reply.bin` — ответ эхо-сервера: ICMP-пакет
  (type=0 code=0, тот же id/seq/данные, чексумма посчитана верно).

ICMP Echo Request:

| Поле | Размер |
| ------ | -------- |
| type | 1 (8 = echo) |
| code | 1 (0) |
| checksum | 2 |
| id | 2 (BE) |
| sequence | 2 (BE) |
| данные | произвольные |

Чексумма — сумма 16-битных слов (BE) с переносом старшего бита обратно
(`carry fold`), инвертированная; при расчёте поле чексуммы — нули.
Нечётный хвост дополняется нулевым байтом.

## Часть 1 — Сборка пакета

Прочитай параметры из `input.txt` и собери пакет Echo Request:
`08 00 <checksum> 12 34 00 01 68 65 6c 6c 6f`. Выведи его hex
(заглавные, через пробел).

### Выход

```text
PACKET: 08 00 A1 F8 12 34 00 01 68 65 6C 6C 6F
```

## Часть 2 — Проверка ответа

Прочитай `reply.bin`: пересчитай чексумму (поле чексуммы в пакете при
расчёте — нули), сверь `id` и `seq` с запросом и выведи итог.

### Выход

```text
CHECKSUM OK: 0xA9F8
ID=0x1234 SEQ=0x0001
REPLY OK: 5 bytes
```

## Подсказки

- Fold: `sum = (sum & 0xFFFF) + (sum >> 16)`, повторять, пока не
  влезет; финал — `~sum & 0xFFFF`.
- Слова — big-endian: `0x0800`, затем `0x0000` (чексумма), `0x1234`...
- У запроса и ответа разные type, поэтому чексуммы отличаются.
