# Миссия 052 — Эхо ICMP

> Уровень: `★★★★☆` · Тема: ICMP, raw-сокеты, контрольные суммы

ICMP-эхо — как эхо в горах: послал сигнал — вернулся. Но в горах Сетки эхо иногда возвращается не с
тем лицом.
— Проверь, что отвечает, — Зен откидывается в кресле. — А потом — кто отвечает.
Джез шлёт эхо и считает контрольные суммы ответов, чтобы понять, настоящее ли это эхо.

## Часть 1 — Сборка пакета

ICMP Echo Request:

| Поле | Размер |
| ------ | -------- |
| type | 1 (8 = echo) |
| code | 1 (0) |
| checksum | 2 |
| id | 2 (BE) |
| sequence | 2 (BE) |
| данные | произвольные |

Чексумма — сумма 16-битных слов (BE), с переносом старшего бита обратно
(`carry fold`), инвертированная. Реализуй функцию checksum и проверь
на пакете:

```text
type=8 code=0 id=0x1234 seq=0x0001 data="hello"

## Подсказки

- Fold: `sum = (sum & 0xFFFF) + (sum >> 16)` повторять, пока не
  влезет; финал — `~sum & 0xFFFF`.
- Слова — big-endian (старший байт первым) — смотри на hex дамп выше.
- В среде без root проверь только часть 1 (сборку и чексумму).
