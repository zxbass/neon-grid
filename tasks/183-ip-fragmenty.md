# 183 — IP-фрагментация

> Уровень: `★★★★☆` · Тема: IP · фрагментация

IP-фрагменты: одно сообщение, разрезанное на куски и разлетевшееся разными путями. Джез собирает
письмо из обрывков.
— Письмо режут на части, — Зен показывает фрагменты. — Но порядок всегда записан в заголовке.
Джез читает порядок.

---

## Данные

- `data/183/fragments.txt` — три фрагмента hex

## Часть 1

Для каждого: `FRAG <i>: ID=0x1337 OFF=<смещение> LEN=<данные> MF=<0/1>`.

## Часть 2

Верни `OFFSET <off>: <данные фрагмента как текст>` для каждого и последней строкой
`REASSEMBLED: <все данные>`.
