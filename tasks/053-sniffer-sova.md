# Миссия 053 — Сниффер «Сова»

> Уровень: `★★★★☆` · Тема: разбор пакетов, IPv4/TCP

Сова-сниффер сидит на проводе и слушает всё, что течёт мимо. Джез впервые надевает наушники и
слышит, как Сетка дышит.
— Не всё, что слышно, предназначено для твоих ушей, — CROW предупреждает без улыбки. — Но всё, что
слышно, можно понять.
Джез слушает записанный трафик и раскладывает чужие пакеты по полочкам.

---

## Данные

Файл `data/053/capture.pcap` — запись трафика (little-endian магия
`0xd4c3b2a1`, linktype 1 = Ethernet). Глобальный заголовок 24 байта:

| Смещение | Поле |
| ---------- | ------ |
| 0 | магия (LE) |
| 4 | версия (2×u16) |
| 20 | linktype (u32) |

Затем записи: 16 байт заголовка (ts_sec, ts_usec, incl_len, orig_len
— все u32 LE) + данные пакета.

## Часть 1 — Заголовки записей

Прочитай файл и выведи для каждого пакета длину и время захвата.

### Выход

```text
PKT 0: len=54 ts=1234567890.123456
PKT 1: len=54 ts=1234567890.123789
PKT 2: len=72 ts=1234567890.124011
```

## Часть 2 — Разбор Ether/IP/TCP

Ethernet: dst(6) src(6) ethertype(2; 0x0800=IPv4). IPv4: ver/ihl(1),
len(2 BE), proto(1; 6=TCP), src(4), dst(4). TCP: sport(2) dport(2),
seq(4), ack(4), флаги — байт 13 заголовка TCP.

Выведи для каждого пакета поток и длину полезной нагрузки, затем
найди пакет, где есть SYN (`0x02`) без ACK.

### Выход

```text
10.0.0.1:51234 -> 10.0.0.2:80 (TCP flags=0x02 len=0)
10.0.0.2:80 -> 10.0.0.1:51234 (TCP flags=0x12 len=0)
10.0.0.1:51234 -> 10.0.0.2:80 (TCP flags=0x18 len=18)
SYN: 10.0.0.1:51234 -> 10.0.0.2:80
```

## Подсказки

- Магия определяет порядок байт во всех числах файла (поля IP/TCP
  всегда BE).
- Младший ниббл `ver/ihl` — длина IP-заголовка в 32-битных словах:
  смещение TCP-заголовка — `14 + ihl*4`.
- `len` в части 2 — длина данных TCP (без заголовков).
