# Миссия 041 — Пинг в шлюз

> Уровень: `★☆☆☆☆` · Тема: TCP-подключение, разведка

Первый выход в Сеть. Джез сидит в кресле «Гаража», провода идут от шеи к серверу, и Зен впервые не
даёт ей шпаргалку.
— Пинг — это вежливый стук в дверь, — он говорит, не оборачиваясь. — Постучи — и узнаешь, кто дома.
Джез стучит. Кто-то отвечает.

---

## Данные

- `data/041/hosts.txt` — строки `host port` (порт от 1 до 65535);
- `data/041/banners.txt` — строки `port баннер` для открытых портов.
  Порт, которого нет в `banners.txt`, считается закрытым.

## Часть 1 — Проверка порта

Прочитай `hosts.txt` построчно. Для каждого `host port` посмотри, есть ли
порт в `banners.txt`. Если есть — порт открыт, иначе — закрыт:

- открытый: `host port    -> OPEN` (четыре пробела перед `->`);
- закрытый: `host port  -> CLOSED` (два пробела перед `->`).

### Выход

```text
127.0.0.1 23    -> OPEN
127.0.0.1 9999  -> CLOSED
127.0.0.1 8080    -> OPEN
127.0.0.1 1200    -> OPEN
```

## Часть 2 — Баннер

Для каждого открытого порта из `hosts.txt` выведи баннер из
`banners.txt` (всё, что после номера порта) строкой
`BANNER: <текст>`. Неоткрытые порты пропускай.

### Выход

```text
BANNER: OMEGA-DYNE GATEWAY v2.1 // UNAUTHORIZED ACCESS IS FELONY
BANNER: Apache/2.4.41 (Unix) mod_ssl/2.4.41
BANNER: NEON-CHAT/0.9 READY
```

## Подсказки

- Читай файлы построчно, строки не должны содержать переводов строк
  в конце.
- Баннер бери целиком — не обрезай по пробелам.
- Порядок строк в выводе — порядок строк в `hosts.txt`.
