# 209 — Конвейер

> Уровень: `★★★★☆` · Тема: пайплайны · goroutines

CROW гонит поток событий с метками времени. Джез обрабатывает их по одному, и Дон качает головой:
«Обработка дешевле, чем ожидание. Гоняй конвейером».
— Одна рука моет другую, — Зен передаёт Джез чашку. — Три стадии — три руки. Никто не ждёт, пока
домоют всю посуду.
Джез собирает конвейер из трёх рук.
