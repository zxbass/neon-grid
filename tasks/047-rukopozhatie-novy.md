# Миссия 047 — Рукопожатие «Новы»

> Уровень: `★★★☆☆` · Тема: WebSocket-хендшейк, SHA-1, Base64

Рукопожатие — первый обмен между клиентом и сервером: ключ, приветствие, ответ. Если руки не сошлись
— дверь не откроется.
— В Сетке не здороваются дважды, — Прах говорит это так, будто за этим стоит опыт. — Поздороваешься
неправильно — и тебя уже нет.
Джез учится здороваться правильно.

---

## Данные

- `data/047/handshake.txt` — строка `key: <base64>` — ключ клиента
  из заголовка `Sec-WebSocket-Key`;
- `data/047/frame.bin` — один текстовый фрейм от сервера
  (незамаскированный).

## Часть 1 — Хендшейк

Сервер отвечает на хендшейк заголовком:

```text
Sec-WebSocket-Accept: base64(SHA1(key + "258EAFA5-E914-47DA-95CA-C5AB0DC85B11"))
```

Прочитай ключ из `handshake.txt`, вычисли `Accept` и выведи:

### Выход

```text
ACCEPT MATCH: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

## Часть 2 — Фрейм данных

Разбери `frame.bin` — текстовый фрейм от сервера (без маски):

- байт 0: FIN(1 бит) + opcode (4 бита; 1 = text, 8 = close);
- байт 1: mask bit + длина (7 бит; если 126 — длина в 2 байта BE);
- данные.

Выведи текст фрейма:

### Выход

```text
FRAME: MERCURY_IS_AWAKE
```

## Подсказки

- Длина 126/127: 7-битное значение `126` означает, что длина в
  следующих 2 байтах (BE).
- Клиентские фреймы маскируются обязательно; серверные — нет, маску
  снимать не нужно.
- Base64: стандартный алфавит с `=`-паддингом.
