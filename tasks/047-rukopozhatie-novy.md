# Миссия 047 — Рукопожатие «Новы»

> Уровень: `★★★☆☆` · Тема: WebSocket-хендшейк, SHA-1, Base64

Рукопожатие — первый обмен между клиентом и сервером: ключ, приветствие, ответ. Если руки не сошлись — дверь не откроется.
— В Сетке не здороваются дважды, — Прах говорит это так, будто за этим стоит опыт. — Поздороваешься неправильно — и тебя уже нет.
Джез учится здороваться правильно.

---

## Часть 1 — Хендшейк

Клиент отправляет:

```
GET /socket HTTP/1.1\r\n
Host: 127.0.0.1:8080\r\n
Upgrade: websocket\r\n
Connection: Upgrade\r\n
Sec-WebSocket-Key: <случайные 16 байт, base64>\r\n
Sec-WebSocket-Version: 13\r\n
\r\n
```

Сервер отвечает `101 Switching Protocols` и заголовком:

```
Sec-WebSocket-Accept: base64(SHA1(key + "258EAFA5-E914-47DA-95CA-C5AB0DC85B11"))
```

Реализуй вычисление `Accept` и проверь по известному примеру
(RFC 6455):

```
key   = dGhlIHNhbXBsZSBub25jZQ==
accept= s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

### Выход

```
ACCEPT MATCH: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

## Часть 2 — Фрейм данных

После хендшейка сервер шлёт текстовый фрейм. Формат:

- байт 0: FIN(1 бит) + opcode (4 бита; 1 = text, 8 = close);
- байт 1: mask bit + длина (7 бит; если 126 — длина в 2 байта BE);
- маска 4 байта (если mask=1, клиент→сервер — всегда замаскировано);
- данные.

Разбери фрейм от сервера (без маски) и выведи текст:

### Выход

```
FRAME: MERCURY_IS_AWAKE
```

## Подсказки

- Длина 126/127: 7-битное значение `126` означает, что длина в
  следующих 2 байтах (BE).
- Клиентские фреймы маскируются обязательно; серверные — нет.
- XOR маски: `data[i] ^ mask[i % 4]`.
