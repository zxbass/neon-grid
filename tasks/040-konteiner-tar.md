## Часть 1 — Заголовок

Каждая запись — 512 байт:

| Смещение | Поле |
| ---------- | ------ |
| 0 | имя файла (100 байт, до NUL) |
| 100 | режим (8 байт, octal) |
| 108 | uid (8 байт, octal) |
| 116 | gid (8 байт, octal) |
| 124 | размер (12 байт, octal) |
| 136 | mtime (12 байт, octal) |
| 148 | чек-сумма (8 байт, octal) |
| 156 | typeflag (1 байт) |
| 257 | магия `ustar` (6 байт) |

Выведи для каждой записи:

```text
name=HEIST_PLAN.TXT size=4096 mode=0644 type=0 mtime=1000000000

## Часть 2 — Распаковка и чек-сумма

После каждого 512-байтного заголовка идут `ceil(size/512)` блоков
данных по 512 байт (последний дополнен нулями).

Проверь чек-сумму: сумма всех байт заголовка, где поле чек-суммы
считается как 8 пробелов (`0x20`), по модулю 2^16. Сравни с записью.
Затем распакуй файлы в поддиректорию `out/`.

### Выход

```text
HEIST_PLAN.TXT: EXTRACTED (cksum OK)
TRACKING.DB: EXTRACTED (cksum BAD)

## Подсказки

- Octal → int: `int(s, 8)` или руками.
- Чек-сумма считается с байтами 0x20 в поле чек-суммы (важный нюанс!).
- Конец архива — два нулевых 512-байтных блока подряд.
- `typeflag` 0 или `'0'` — обычный файл, `'5'` — директория (пропусти
  данные, размер 0).
