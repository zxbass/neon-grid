# Миссия 099 — Кадры «Проектора»

> Уровень: `★★★★☆` · Тема: видео, RLE-кадры, дельта-кодирование

Кадры проектора: видео, разложенное на кадры, каждый кадр — картинка. Джез разбирает поток и находит кадр, который никто не должен был увидеть.
— Фильм — это ложь, которая происходит 24 раза в секунду, — CROW щурится. — И между ложью иногда прячут правду.
Джез ищет правду между кадрами.

---

## Часть 1 — Кадр-дельты

Формат потока `projector.bin`:

- первые 4 байта: ширина (u16 LE) + высота (u16 LE);
- кадр 0: полный — `0xFF`, затем `W*H` байт (индекс палитры 0–15);
- кадры i>0: `0x00` + число прямоугольников (u16 LE), каждый:
  `x(u16) y(u16) w(u16) h(u16) data(w*h байт)`.

Восстанови все кадры (накладывай дельты) и выведи, сколько пикселей
меняется между кадрами:

```
FRAME 0: full (1024 px)
FRAME 1: 2 rects, 96 px changed
FRAME 2: 1 rect, 48 px changed
```

## Часть 2 — Палец на экране

На одном из кадров появляется «палец» — прямоугольник, целиком
закрашенный одним цветом, отличным от фона. Найди кадр и координаты
прямоугольника:

```
FRAME 3: pointer at (12, 8) size 4x4 color=7
```

## Подсказки

- Дельты накладываются на предыдущий кадр в памяти.
- «Палец» = прямоугольник, где все байты равны и != большинству фона
  этого кадра.
- Палитру рисуй как в 095, если нужна визуализация.
