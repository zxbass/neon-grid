## Часть 1 — Заголовок загрузчика

Файл `boot.bin` начинается с 512 байт. Тебе нужно прочитать первые
**16 байт** и вывести их как шестнадцатеричную строку в верхнем
регистре, разделяя байты пробелом.

Пример файла (первые 16 байт):

```
EB 3C 90 4D 53 44 4F 53 35 2E 30 00 02 01 01 00
```

Выход для этих байтов — строка вида:

```
EB 3C 90 4D 53 44 4F 53 35 2E 30 00 02 01 01 00
```

Считать файл нужно **побайтно**, не как текст.

### Входные данные

Бинарный файл `boot.bin` (512+ байт), путь передаётся аргументом
или читается из stdin как поток байт.

### Ответ

Строка из 16 байт в hex, разделённых пробелом.

## Часть 2 — Сумма бутсектора

Настоящий бутсектор заканчивается сигнатурой `55 AA` (байты `0x55`,
`0xAA`) на последних двух байтах. Проверь, что `boot.bin` действительно
загрузчик: найди байты по смещению `510` и `511` и выведи `BOOT OK`,
если они равны `0x55 0xAA`, иначе `BOOT BAD`.

Кроме того, посчитай сумму всех 512 байт (как беззнаковые байты) по
модулю 256 и выведи её в hex. Сумма поможет Зену сверить контрольную
печать кузнеца из будущих миссий.

### Пример ответа

```
BOOT OK
SUM: 0x7A
```

## Подсказки

- Файл открывай в режиме «бинарный», а не «текстовый» — иначе на Windows
  будет порча данных.
- `read(16)` вернёт ровно 16 байт, только если файл достаточно длинный.
- Для второй части используй `seek(510, SEEK_SET)` или прочитай файл
  целиком в массив.
