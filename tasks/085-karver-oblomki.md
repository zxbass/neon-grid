# Миссия 085 — Карвер «Обломки»

> Уровень: `★★★★☆` · Тема: file carving, форензика

Карвер обломков: из мусорного сектора — целый файл. Джез впервые восстанавливает данные из того, что
все считали мусором.
— Мусор — это данные, которые ждут, — Крем подмигивает. — Умеешь ждать вместе с ними — найдёшь
сокровище.
Джез ждёт и находит.

---

## Часть 1 — Поиск сигнатур

В сыром дампе `dump.bin` (несколько МБ) ищи сигнатуры файлов:

| Тип   | Сигнатура     |
|-------|---------------|
| JPEG  | `FF D8 FF`    |
| PNG   | `89 50 4E 47` |
| ZIP   | `50 4B 03 04` |

Выведи позиции всех вхождений:

```text
JPEG @ 0x00000000
PNG  @ 0x00123ABC
ZIP  @ 0x00300000
```

## Часть 2 — Восстановление

Для каждого файла определи конец:

- PNG — чанк `IEND` + 4 байта (длина 0, тип `IEND`, CRC);
- JPEG — байты `FF D9`;
- ZIP — центральная директория: ищи `50 4B 01 02` с конца (последнее
  вхождение) + 22 байта.

Вырежи байты `[start, end]` в файлы `carved_N.ext` и выведи их размеры:

```text
carved_0.jpg 89222 bytes
carved_1.png 12345 bytes
carved_2.zip 4051 bytes
```

## Подсказки

- Ищи сигнатуры наивным поиском (O(n·m) ок для МБ) или алгоритмом КМП.
- Проверь, что `end > start` и `end <= len(dump)` — иначе `TRUNCATED`.
- ZIP: последний `EOCD` (конец) отступает — при вырезании используй
  `eocd_pos + 22`.
