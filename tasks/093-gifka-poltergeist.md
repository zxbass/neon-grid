# Миссия 093 — Гифка «Полтергейст»

> Уровень: `★★★★★` · Тема: GIF-декодер, LZW, интерлейсинг

GIF-ка-полтергейст: анимация, которая двигается сама, как будто в файле кто-то живёт. Джез разбирает
GIF и находит кадры, которых там быть не должно.
— Анимация — это память о движении, — Син смотрит на кадры. — А движение иногда оставляет следы.
Джез ищет следы между кадрами.

---

## Часть 1 — Заголовок и LSD

GIF:

- сигнатура `GIF87a`/`GIF89a`;
- Logical Screen Descriptor: ширина (u16 LE), высота (u16 LE), флаги,
  цвет фона, aspect;
- глобальная таблица цветов (если флаг).

Разбери и выведи:

```text
GIF89a 640x480 global_colors=256 bg=0
```

## Часть 2 — Кадры и LZW

Каждый блок `0x2C` (image descriptor) + LZW-сжатые данные:

- минимальный код `LZW_MIN` (1 байт);
- sub-blocks: `размер` (1 байт) + данные;
- конец `0x00`.

LZW-декодер с таблицей цветов: коды → индексы палитры → пиксели.
Интерлейсинг: ряды 0,8,16… затем 4,12… затем 2,6… затем 1,3,5…

Для каждого кадра выведи размер, палитру (если локальная) и задержку
(`0x21` блок graphic control: delay u16 в 10 мс). Найди кадры, где
индекс пикселя в палитре равен значению, которое образует ключ:
проберись по кадрам и собери «секретный слой» — пиксели, где
`palette_index` в кадре i меняется:

### Выход

```text
FRAME 0: 640x480 delay=10 local_pal=no
...
KEY LAYER: 4e 45 4f 4e -> NEON
```

## Подсказки

- LZW в GIF: коды 2..12 бит, растут по мере заполнения словаря.
- Clear code = 1 << min_code; EOI = clear+1.
- Интерлейсинг меняет порядок строк — не забудь.
- GCE может идти перед каждым image block.
