# Миссия 055 — Многохоповый луч

> Уровень: `★★★★☆` · Тема: релейные сети, маршрутизация

Многопрыжковый луч: сообщение, которое перескакивает от узла к узлу, чтобы никто не увидел, кто
говорит и кому. На нижних уровнях так передают цены и угрозы.
— Прыжок — это ложь, которая помогает правде, — Син смотрит на карту маршрутов. — Каждый узел
думает, что говорит с ним.
Джез проводит луч через цепочку узлов и считает, сколько раз он успел сменить лицо.

---

## Часть 1 — Реле

Реле: слушает порт `P`, умеет в команды:

- `FWD <port>` — все входящие после этой команды пересылаются на
  `127.0.0.1:<port>`;
- `BACK <port>` — всё, что приходит обратно с `port`, ретранслируется
  клиенту;
- `IDLE` — ничего не делать.

Реализуй реле как сервер с двумя сокетами (вход и пересылка).

### Выход

```bash
$ ./relay 2001
[relay] FWD 2002

## Часть 2 — Цепочка

Цепочка из 3 релеев: `client → R1(2001) → R2(2002) → R3(2003) → echo(1200)`.
Клиент шлёт на 2001 команды `FWD 2002`, `FWD 2003`, `FWD 1200` и затем
данные. Эхо возвращается по обратной цепочке. Логируй каждый хоп:

### Выход

```text
[hop1] 2001 -> 2002
[hop2] 2002 -> 2003
[hop3] 2003 -> 1200
[hop3] 1200 <- echo
[hop2] 2003 <- 2002
[hop1] 2002 <- 2001
ROUNDTRIP OK

## Подсказки

- Каждое реле держит пару (входной сокет, выходной сокет) — обмен
  двусторонний.
- `FWD` без закрытия старого канала: если второй `FWD` — переключайся.
- Проверяй, что клиент может слать команды и данные по одному
  соединению подряд.
