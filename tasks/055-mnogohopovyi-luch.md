# Миссия 055 — Многохоповый луч

> Уровень: `★★★★☆` · Тема: релейные сети, маршрутизация

Многопрыжковый луч: сообщение, которое перескакивает от узла к узлу, чтобы никто не увидел, кто
говорит и кому. На нижних уровнях так передают цены и угрозы.
— Прыжок — это ложь, которая помогает правде, — Син смотрит на карту маршрутов. — Каждый узел
думает, что говорит с ним.
Джез разбирает лог прохождения луча через цепочку узлов и считает, сколько раз он сменил лицо.

---

## Данные

Файл `data/055/hoplog.txt` — лог сессии трёх релеев. Строки:

- `C: <port> FWD <port>` — клиент настроил реле: всё, что приходит
  на первый порт, пересылается на второй;
- `H: <a> <b> SEND <n>` — переслано n байт от a к b;
- `H: <a> <b> ECHO <n>` — эхо вернулось от a к b;
- `C: <port> RECV <n>` — клиент получил ответ.

## Часть 1 — Конфигурация реле

Прочитай `hoplog.txt` и выведи все команды `FWD` в порядке файла.

### Выход

```text
FWD 2001 -> 2002
FWD 2002 -> 2003
FWD 2003 -> 1200
```

## Часть 2 — Цепочка

Восстанови цепочку: `SEND` — хоп вперёд, `ECHO` — обратно. Номер хопа —
позиция узла в цепочке `FWD` (первый `FWD` — хоп 1). В конце — итог,
если клиент подтвердил приём.

### Выход

```text
[hop1] 2001 -> 2002
[hop2] 2002 -> 2003
[hop3] 2003 -> 1200
[hop3] 1200 <- 2003
[hop2] 2003 <- 2002
[hop1] 2002 <- 2001
ROUNDTRIP OK
```

## Подсказки

- Цепочка `FWD`: 2001→2002→2003→1200; `ECHO` идёт по ней же назад.
- Для `ECHO` номер хопа определяется по порту-источнику (1200 — хоп 3).
- `ROUNDTRIP OK` появляется только если есть `C: ... RECV`.
