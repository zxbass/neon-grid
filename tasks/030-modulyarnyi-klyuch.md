# Миссия 030 — Модулярный ключ

> Уровень: `★★★★☆` · Тема: модулярная арифметика, шифр «маленький RSA»

Модульный ключ RSA у ворот корпоративного архива. Кто-то зашифровал сообщение открытым ключом, но
оставил след: модуль собран из двух простых чисел, а сами числа спрятаны в обрывках конфигурации.
— RSA — это замок, где ключ — знание, — Зен поднимает два пальца. — Знание о том, из чего сделан
модуль.
Джез перемножает и раскладывает, и дверь архива поддаётся.

---

## Часть 1 — Возведение и обратное

Реализуй быстрый `pow(a, b, mod)` (бинарное возведение в степень,
не используй встроенный `pow` тройной — сделай руками) и поиск
мультипликативного обратного `inv(a, mod)` (расширенный алгоритм
Евклида). Проверь:

```text
pow(7, 11, 143)  -> 106
inv(7, 143)      -> 41     (7*41 = 287 = 2*143 + 1)
```

### Выход

```text
POW=106 INV=41
```

## Часть 2 — Взлом «маленького» RSA

«Шифр кузнеца»:

- `n = p*q`, оба простых **меньше 1000**;
- `e = 65537` (постоянно);
- `c = m^e mod n`.

Тебе даны `n` и `c`. Взлом:

1. Разложи `n` на множители перебором (`p ≤ q`).
2. `phi = (p-1)*(q-1)`.
3. `d = inv(e, phi)`.
4. `m = pow(c, d, n)`.

Дано:

```text
n = 143
c = 50
```

Выведи `m` как число, и как ASCII-символ, если m в диапазоне 32–126
(иначе — только число).

### Выход

```text
m=7
p=11 q=13 d=113
```

## Подсказки

- Множители перебирай только до `sqrt(n)`.
- Расширенный Евклид вернёт отрицательный `d` — приведи к `[0, phi)`.
- Если `m` вне печатного диапазона, выведи только число.
