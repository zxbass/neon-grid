# 188 — HTTP-сниффер

> Уровень: `★★★★☆` · Тема: HTTP · перехват

HTTP-трафик, перехваченный на входе в «Гараж»: запросы, ответы, коды. Джез учится читать разговоры, которые машины ведут через порт 80.
— HTTP — это разговор, — Дон пожимает плечами. — У каждого разговора есть первая строка.
Джез читает первые строки.
