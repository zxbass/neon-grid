# 172 — Тетрис-блок

> Уровень: `★★★☆☆` · Тема: тетрис · симуляция

Тетрис из старого терминала: фигуры падают, строки тают. Джез пишет симуляцию падения и понимает:
весь мир — это фигуры, которые ищут, куда лечь.
— Падение — это тоже движение, — Зен поправляет очки. — Просто в одну сторону.
Джез следит за падением.

---

## Данные

- `data/172/pieces.txt` — буквы фигур через пробел

## Правила симуляции

Поле: 6 строк по 10 столбцов (пустая клетка — `.`).

Форма фигуры задана строками, в каждой строке — столбцы клеток:

| Буква | Форма |
| ----- | ----- |
| `I` | `{0,1,2,3}` |
| `O` | `{0,1}` / `{0,1}` |
| `T` | `{0,1,2}` / `{1}` |
| `S` | `{1,2}` / `{0,1}` |
| `Z` | `{0,1}` / `{1,2}` |
| `J` | `{0}` / `{0,1,2}` |
| `L` | `{2}` / `{0,1,2}` |

Каждая фигура:

1. появляется у верхнего края поля, левый столбец фигуры — `x = 3`;
2. падает вниз, пока все её клетки свободны (не выходят за нижний край
   поля и не пересекаются с уже закреплёнными фигурами);
3. закрепляется на месте, клетки поля заполняются буквой фигуры;
4. полные строки удаляются: строки выше сдвигаются вниз, сверху
   появляется пустая строка, счётчик очищенных строк растёт.

## Часть 1

Верни финальное поле: 6 строк по 10 символов (буква фигуры, `.` — пусто).

## Часть 2

Верни `LINES CLEARED: <n>` и `PIECES: <сколько фигур>`.
