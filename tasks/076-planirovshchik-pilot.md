# Миссия 076 — Планировщик «Пилот»

> Уровень: `★★★☆☆` · Тема: планировщики задач, приоритеты

Планировщик-пилот: задачи, дедлайны, приоритеты — и только одно ядро, которое всеми вертит. Джез
пишет планировщик и учится главному: не всё важное — срочное.
— Пилот решает, кто летит, — Зен смотрит, как Джез расставляет приоритеты. — А кто просто стоит в
очереди.
Джез расставляет очереди и понимает, что иногда лучше постоять.

---

## Часть 1 — FIFO и приоритет

Задачи: `id`, `приоритет` (1–10), `время` (мс). Планировщик:

- режим `fifo`: строго по порядку поступления;
- режим `prio`: по приоритету (выше число = раньше), при равенстве —
  по времени поступления.

Вход — список задач (время выполняется `sleep(t)` воркером-одиночкой).
Выведи порядок выполнения и суммарное время:

```text
fifo:  t1 t2 t3 t4  total=210ms
prio:  t4 t2 t1 t3  total=210ms
```

## Часть 2 — Вытесняющий (round-robin)

Несколько воркеров (W), каждая задача режется на кванты по 10 мс.
RR-планирование: воркеры берут задачи по кругу, «дожимают» кванты.
Приоритетные задачи получают 2 кванта подряд.

Посчитай «задержку» каждой задачи (время от поступления до завершения)
и среднюю:

```text
W=2 RR:  avg_delay=47.5ms  (t1=20 t2=60 t3=75)
```

## Подсказки

- Структура «таск» с полями `arrival`, `remaining`, `prio`.
- Для prio используй кучу/очередь с приоритетом.
- RR: общий таймер тикает каждые 10 мс, воркеры получают следующий
  квант; задержка = `finish - arrival`.
