# Миссия 054 — Проброс «Червоточина»

> Уровень: `★★★★☆` · Тема: туннели, фрагментация

Червоточина: туннель через чужой узел, чтобы выйти там, где тебя не ждут. Джез прокладывает свой
первый маршрут сквозь чужую инфраструктуру.
— Туннель — это дверь в чужом коридоре, — Прах говорит это со знанием дела. — Главное — чтобы
хозяева не заметили сквозняка.
Джез восстанавливает трафик, который прошёл сквозь червоточину кусками.

---

## Данные

Файл `data/054/frames.bin` — поток фрагментированного трафика. Данные
нарезаны на куски по 8 байт, каждый кусок упакован в кадр:

```text
0x77 | frag_seq(1) | total_frags(1) | data(≤8) | crc8(data)
```

`crc8` — простой XOR всех байт данных. Кадры идут по порядку без потерь.

## Часть 1 — Сборка

Прочитай `frames.bin`, собери фрагменты по `frag_seq` в один поток и
выведи число кадров и собранные данные hex-строкой (заглавные, через
пробел).

### Выход

```text
FRAMES: 4
DATA: 4E 45 4F 4E 20 47 52 49 44 20 49 53 20 41 20 47 48 4F 53 54 20 54 4F 57 4E
```

## Часть 2 — Проверка

Для каждого кадра пересчитай `crc8` и сверь с полем кадра. Если все
совпали — выведи подтверждение.

### Выход

```text
FRAME 0 CRC OK
FRAME 1 CRC OK
FRAME 2 CRC OK
FRAME 3 CRC OK
TUNNEL OK
```

## Подсказки

- `total_frags` — число кадров; последний фрагмент может быть короче 8.
- Кадр заканчивается ровно там, где кончаются данные — длина
  известна из файла.
- XOR-контроль ловит случайные биты — для задачи сойдёт.
