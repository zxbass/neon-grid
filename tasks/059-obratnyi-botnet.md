# Миссия 059 — Обратный ботнет

> Уровень: `★★★★★` · Тема: распределённые вычисления, map-reduce

Обратный ботнет: не атаковать из многих точек, а слушать из многих точек. Джез собирает сеть из чужих прослушек, чтобы услышать целый район сразу.
— Сеть — это уши, — говорит Прах. — Чем больше ушей, тем громче шёпот.
Джез собирает уши и впервые слышит разговор, который шёл через весь квартал.

---

## Часть 1 — Мастер

Координатор: TCP-сервер. Принимает `WORK <id>` от воркеров. Раздаёт
работу по 4096 ключей на кусок (перебор ключей от 0 до 2^24).
Воркер считает свою порцию и возвращает `RESULT <id> <key> <hits>`.

Простейшая «работа» для теста: найти все `key`, где
`hash(key) & 0xFF == 0x42` (hash — твой CRC32 от 4-байтового BE key).
Мастер считает суммарные хиты и время:

### Выход

```
WORKERS: 10  CHUNKS: 4096  HITS: 512
ELAPSED: 1.234s  RATE: 13.6M keys/s
```

## Часть 2 — Живучесть

Воркеры дохнут (по `KILL <id>` от мастера, чтобы симулировать сбой)
или не отвечают. Мастер должен: дать кусок другому воркеру, не терять
уже полученные результаты, завершиться, когда все куски сданы.

Добавь контроль: каждый кусок имеет ид; мастер помечает `DONE`/`LOST`.
Выведи итог с числом пересланных кусков:

### Выход

```
DONE: 512 hits  (124 chunks retried)
```

## Подсказки

- Для тестов используй «виртуальный» ботнет: воркеры — обычные
  функции, вызванные параллельно, и реальные сокеты для проверки.
- CRC32 от key как 4-байт BE; `(crc & 0xFF) == 0x42`.
- Ретрай: кусок, выданный дважды, должен быть только из `LOST`-пула.
