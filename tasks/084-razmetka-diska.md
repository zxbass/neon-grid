## Часть 1 — MBR

Образ диска `disk.img`. Сектор 0: 446 байт кода + 4 записи партиции по
16 байт + сигнатура `0x55AA`.

Запись: статус(1), CHS(3), тип(1), CHS end(3), LBA-старт (u32 LE),
число секторов (u32 LE).

Выведи все записи:

```
PT 0: type=0x0C (FAT32 LBA) start=2048 sectors=614400 size=300.0MB
PT 1: type=0x83 (Linux)     start=616448 sectors=204800 size=100.0MB
```

## Часть 2 — GPT и поиск

Диск размечен GPT: `LBA1` (сектор 1) — заголовок GPT
(`"EFI PART"`, число записей, размер записи, начало массива записей).
Записи: GUID типа (16 байт), GUID партиции, first_lba, last_lba (u64 LE),
имя (36 байт UTF-16).

Найди партицию с именем `MERCURY` и выведи её байтовый диапазон:

```
PARTITION MERCURY: LBA 2048..4096 (1.0MB)
```

## Подсказки

- Проверяй сигнатуры: `55 AA` для MBR, `EFI PART` для GPT — иначе `BAD`.
- Приоритет: GPT, если валидный, иначе MBR (детект по `EFI PART`).
- Имя GPT — UTF-16LE, читай по 2 байта до нулевого символа.
- LBA старт в MBR — секторы; `offset = lba * 512`.
