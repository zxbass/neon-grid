# Миссия 023 — Виженер «Некро»

> Уровень: `★★☆☆☆` · Тема: шифр Виженера

Из «мёртвой зоны» Сетки тянут нить переписки, зашифрованной повторяющимся ключевым словом. Слово известно — но буквы пляшут так, будто им тесно.
— Виженер любит порядок, — Зен рисует на пыльном стекле таблицу. — Найди ритм ключа — и текст ляжет как по струнам.
Джез подбирает ключ и читает чужой разговор. Разговор о том, что Сетка просыпается.

---

## Часть 1 — Расшифровка

Шифрование Виженера (A–Z, без не-букв):

`C[i] = (P[i] + K[i mod len(K)]) mod 26`

Вход — шифротекст и ключ (заглавные, без пробелов):

```
cipher: VFHFVXRQLYIKTMAZIQBVCUIRB
key:    NEON
```

### Выход

```
PLAINTEXT: THEBLACKRIVERRISESAGAIN
```

Проверка первой буквы: `V - N = (21-13) mod 26 = 8 = I`… стоп, проверь
свой результат: должно получиться осмысленное сообщение на английском.

## Часть 2 — Ключ без пробелов

Не-буквы не кодируются, но **счётчик шифрования не сдвигается** на
не-буквах. То есть пробелы и знаки проходят без изменений, а ключ
двигается только по буквам. Восстанови исходный текст с пунктуацией.

```
cipher: XABYG, NRT GSEJZJ. RDLPIIYM EIQ JGWX.
key:    DELTA
```

### Выход

```
PLAINTEXT: CROW, THE SPREADS. TRACKING THE SIGN.
```

## Подсказки

- `mod 26` — бери остаток от положительного: `((a-b)%26+26)%26`.
- Следи, чтобы индекс ключа увеличивался только на буквах.
- Регистр: приводи к верхнему, но можно сохранять оригинальный регистр
  при выводе.
