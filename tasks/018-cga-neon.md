# Миссия 018 — CGA-неон

> Уровень: `★★☆☆☆` · Тема: текст → графика, палитры

На складе «Гаража» пылится монитор восьмидесятых: двадцать пять строк текста, восемьдесят колонок, четыре цвета. Дон утверждает, что на этом экране когда-то крутили важное сообщение, а потом просто выключили.
— Цвета — это тоже язык, — Зен постукивает по корпусу. — Умение считать пиксели — это грамотность.
Джез раскладывает экран на строки и точки и собирает из них буквы, которые никто не читал тридцать лет.

---

## Часть 1 — Байты экрана

Экран — массив из 2000 байт (80×25), каждый байт — код символа.
Файл `screen.bin` — ровно 4000 байт: первые 2000 — коды символов,
байты 2000–3999 — атрибуты. Выведи текст 80 колонок, переведя коды
через шрифт:

```
CGA_FONT.BIN — 2048 байт, 256 символов по 8×8 (8 байт на символ).
```

Бит `1` в байте шрифта = светлый пиксель. Выведи только пиксели
символа как `##` для `1` и `..` для `0` (символы удвоены по ширине).

### Выход

Первые 25 строк по 80 «двойных» колонок:

```
##.....##..##.....##..##......
```

## Часть 2 — Цветной режим

В CGA атрибут (байты 2000–3999) задаёт цвет: низкий ниббл — цвет
символа, высокий — цвет фона, бит 7 — мигание. Цвета CGA:

```
0 чёрный, 1 синий, 2 зелёный, 3 циан, 4 красный, 5 пурпурный,
6 коричневый, 7 белый, 8+ яркие.
```

Выведи статистику: сколько символов какого цвета фона встречается,
и список цветов в порядке убывания частоты:

```
BG COLOR COUNTS: 0:12400 7:6200 1:1000
```

## Подсказки

- Символ `c` рисуется так: строка `y` = `font[c*8 + y]`.
- Атрибут экрана: `attr = screen_bytes[2000 + i]`, фон = `attr >> 4 & 7`.
- Не забывай: первые 2000 байт — коды символов, следующие 2000 — их
  атрибуты (индекс атрибута = индексу символа).
