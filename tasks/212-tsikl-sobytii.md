# 212 — Цикл событий

> Уровень: `★★★★☆` · Тема: event loop · неблокирующий ввод

Омега-Дайн держит миллион соединений в одном потоке — не блокируясь ни на одном. Джез разбирает
журнал цикла событий и учится видеть, как одна рука жонглирует тысячей дел.
— Ждать нельзя, — Зен отбивает такт пальцем. — Можно только вернуться, когда придёт ответ.
Джез возвращается к каждому событию ровно тогда, когда нужно.

---

## Данные

- `data/212/events.txt` — события в порядке поступления: `t=<мкс> type=<read|write|timeout|signal>`,
  у `read`/`write` есть `fd=<номер>`

## Часть 1

Обработай события по порядку. Для каждого выведи `EVENT <t>: <type>` и
` fd=<n>`, если файловый дескриптор указан.

## Часть 2

Верни `COUNTS: read=<n> write=<n> timeout=<n> signal=<n>` и
`IDLE: <мкс>` — максимальный промежуток между соседними событиями.
