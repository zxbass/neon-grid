# Миссия 069 — Редактор с откатом

> Уровень: `★★★☆☆` · Тема: TUI-редактор, undo/redo

Редактор с откатом: каждая правка запоминается, каждая ошибка обратима. Джез пишет редактор, в
котором можно вернуть всё, что было.
— Откат — это роскошь, — Зен смотрит на Джез поверх экрана. — В Сетке её мало кто может себе
позволить.
Джез позволяет себе роскошь ошибаться и возвращаться.

---

## Данные

- `data/069/buffer.txt` — начальный буфер (по строке на строку);
- `data/069/commands.txt` — команды, по одной на строку.

## Часть 1 — Буфер и ввод

Загрузи буфер из `buffer.txt`. Текущая строка помечается префиксом
`>`, остальные — двумя пробелами.

### Выход

```text
> LINE1
  LINE2
  LINE3
```

## Часть 2 — Undo/Redo

Выполни команды из `commands.txt`:

- `i<текст>` — вставить текст в конец текущей строки;
- `d` — удалить текущую строку;
- `j` / `k` — вниз / вверх (в пределах буфера);
- `u` — undo, `r` — redo;
- `p` — печать буфера.

Undo/redo — снимки: перед каждой модифицирующей операцией состояние
(строки + позиция курсора) кладётся в стек undo; `u` восстанавливает
последний снимок и кладёт текущее состояние в стек redo; `r` — наоборот.
Новая модификация очищает стек redo.

Выведи буфер после всех команд (как `p`):

### Выход

```text
  LINE2B
> LINE3
```

## Подсказки

- Снимок — копия списка строк и позиции курсора, мутации не нужны.
- Неограниченная глубина: просто два стека.
- Стек redo очищается только новой модификацией, а не `j`/`k`.
