# 177 — Тайловый редактор

> Уровень: `★★★☆☆` · Тема: тайлы · 2bpp

Тайловый редактор «Гаража»: пиксели, палитры, спрайты. Джез рисует тайлы и понимает: каждая картинка — это просто выбор цвета для каждого квадратика.
— Рисунок — это договорённость, — Крем поправляет очки. — О том, какой номер каким цветом считать.
Джез договаривается с пикселями.

---

## Данные
- `data/177/tile.bin` — 16 байт
- `data/177/palette.txt` — 4 строки RGB

## Часть 1
Отрендерь тайл: символы ` .o#@` по индексу пикселя (0=пробел, 1=точка, 2=o, 3=#). 8 строк по 8 символов.

## Часть 2
Верни `USED: <индексы использованных цветов через запятую, по возрастанию>`.
