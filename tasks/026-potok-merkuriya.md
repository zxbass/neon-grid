# Миссия 026 — Поток «Меркурия»

> Уровень: `★★★☆☆` · Тема: RC4-подобный поточный шифр

В трафике «Гаража» гуляет поток, который никто не подписывал. Он идёт от МЕРКУРИЯ — старого ИИ
Сетки, который, по словам Дона, «спит уже десять лет». Спит ли?
— Поток — это пульс, — Син кладёт ладонь на корпус сервера. — Пульс можно прослушать.
Джез прослушивает поток и понимает: МЕРКУРИЙ не спит. Он считает.

---

## Часть 1 — Реализация потока

Алгоритм:

1. KSA: `S[i] = i` для 0..255, затем перемешивание по ключу.
2. PRGA: `i = (i+1) mod 256; j = (j + S[i]) mod 256; swap; k = (S[i] + S[j]) mod 256; out = S[k]`.
3. `cipher[i] = plain[i] XOR out`.

Реализуй полностью (без использования готовых библиотек RC4).
Вход: ключ (ASCII) и hex-шифротекст.

```text
key:      MERCURY
cipher:   21 3b 4e 5a 6f ...

## Часть 2 — Сброс потока

Некоторые фреймы протокола «Меркурий» начинаются заново (reset):
флаг `RST` в байте 0 шифротекста = 1 (сам бит зашифрован!). То есть
для каждого фрейма длина префикса определяет, был ли сброс. Известно:
если байт 0 фрейма после XOR-пирвого байта потока даёт `0x80`, то
поток для этого фрейма стартует снова.

Перехвачено 3 фрейма. Расшифруй каждый, учитывая сбросы, и выведи
содержимое после первых 4 байт (заголовок фрейма отбрось):

### Выход

```text
FRAME 0: HELLO_MERCURY
FRAME 1: AWAKE_AT_MIDNIGHT
FRAME 2: GRID_IS_CLOSING

## Подсказки

- RC4 симметричен: шифрование == расшифровка.
- S-box не модифицируется между вызовами — поток продолжается; при
  сбросе пересоздавай S из ключа.
- Ключ и поток байт — только беззнаковые 0..255.
