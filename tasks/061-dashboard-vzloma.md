# Миссия 061 — Дашборд взлома

> Уровень: `★★☆☆☆` · Тема: TUI, progress-бары, ANSI

Панель взлома — приборная доска нетраннера: статусы, прогресс, цели. Джез впервые рисует собственный
интерфейс, в котором будет жить её работа.
— Интерфейс — это твоя комната, — Дон показывает на пустой экран. — Обустрой её так, чтобы в ней
можно было работать.
Джез обустраивает комнату и впервые чувствует себя дома в чужой Сетке.

---

## Часть 1 — Терминальный бар

Выведи в терминал `progress-bar`:

```text
[##########............] 40%
```

- ширина бара 20 символов;
- заполнение — символ `#`, пусто — `.`;
- процент — число с одним знаком после запятой.

Вход — значение `40` (целое 0..100).

## Часть 2 — Живой дашборд

Построй анимированный экран: каждые 100 мс обновляй (ANSI `\r` + очистка
строки, или `\x1b[H` перерисовка):

- три бара: «ICE breach», «Data leak», «Trace level»;
- процент каждого растёт по своей формуле (`sin`-волны или шаг);
- подписи выровнены, рамка из `+-|`.

Работает 10 секунд, потом выводится финальная строка:

```text
MISSION 061 COMPLETE // trace 78%
```

### Выход (последний кадр)

```text
+----------------------------------+
| ICE breach   [##################] 98% |
| Data leak    [#########.........] 48% |
| Trace level  [############.......] 64% |
+----------------------------------+
```

## Подсказки

- `\x1b[2K` стирает строку, `\r` возврат каретки — минимум ANSI.
- Чтобы не мигало, не печатай новую строку (`\n`), а перезаписывай.
- Для теста без TTY достаточно печатать каждый кадр в файл и проверять
  последний.
