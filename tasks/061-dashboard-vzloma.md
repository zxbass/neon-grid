# Миссия 061 — Дашборд взлома

> Уровень: `★★☆☆☆` · Тема: TUI, progress-бары, отрисовка кадра

Панель взлома — приборная доска нетраннера: статусы, прогресс, цели. Джез впервые рисует собственный
интерфейс, в котором будет жить её работа.
— Интерфейс — это твоя комната, — Дон показывает на пустой экран. — Обустрой её так, чтобы в ней
можно было работать.
Джез обустраивает комнату и впервые чувствует себя дома в чужой Сетке.

---

## Данные

- `data/061/progress.txt` — значение прогресса (целое 0..100) для Части 1;
- `data/061/dash.txt` — финальный кадр дашборда: строки `имя процент`
  (имя из одного-двух слов, процент — целое 0..100).

## Часть 1 — Терминальный бар

Прочитай значение из `progress.txt` и выведи `progress-bar`:

- ширина бара 20 символов;
- заполнение — символ `#`, пусто — `.`;
- число `#` — целая часть `значение * 20 / 100`;
- справа — процент (`%d%%`).

### Выход

```text
[########............] 40%
```

## Часть 2 — Живой дашборд

Отрисуй финальный кадр по `dash.txt`: для каждой строки `имя процент`
выведи строку рамки. Формат строки:

```text
| %-11s [%s] %2d%% |
```

- имя выравнивается по левому краю до 11 символов;
- бар — 20 символов (`#` по `процент * 20 / 100`, остальное `.`);
- рамка: сверху и снизу `+` + 40 символов `-` + `+`.

После рамки выведи финальную строку:

```text
MISSION 061 COMPLETE
```

### Выход

```text
+----------------------------------------+
| ICE breach  [###################.] 98% |
| Data leak   [#########...........] 48% |
| Trace level [############........] 64% |
+----------------------------------------+
MISSION 061 COMPLETE
```

## Подсказки

- Один кадр — один `fmt.Sprintf` на строку, без ANSI-последовательностей:
  тест сравнивает текст кадра как есть.
- Не добавляй лишних пробелов: ширины фиксированы.
