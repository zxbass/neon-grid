# Миссия 116 — Подделка логов

> Уровень: `★★★★☆` · Тема: антифорензика, целостность логов

Подделка логов: история, которую можно переписать. Джез учится редактировать прошлое так, чтобы оно выглядело настоящим.
— Логи — это история, — Син смотрит на строки. — А историю пишут те, кто остаётся в живых.
Джез учится оставаться в живых в чужих логах.

---

## Часть 1 — Проверка цепочки

Лог `access.log` (строки формата из 080) + файл `chain.txt` — по
строке на запись: `sha256(предыдущий_хэш + строка_лога)`. Первый хэш
цепочки — от пустой строки. Проверь целостность: найди первую строку,
где хэш не сходится:

```
LINE 47: HASH MISMATCH (expected a1b2... got c3d4...)
```

## Часть 2 — Устойчивая подделка

Хочешь изменить строку 30 (заменить IP) — придётся пересчитать всю
цепочку **от 30 до конца**, и перезаписать `chain.txt`. Сделай это
честно (найди все строки с IP `10.0.0.66`, замени на `10.0.0.7`) и
покажи, что цепочка после пересчёта сходится:

```
PATCHED: 3 lines rewritten, chain recomputed
VERIFY: OK (entire chain)
```

Затем ответь на вопрос: как форензик узнает о подделке, если цепочка
сходится? (Подсказка: измени `hashlist.txt`/временные метки.) Выведи
свою версию защиты:

```
WEAKNESS: first entry unsigned -> need anchor
```

## Подсказки

- SHA-256 от конкатенации предыдущего хэша (64 hex-символа, как
  строка) и строки лога с `\n` — определи формат и придерживайся.
- Строки нумеруются с 1.
- Антифорензика-ответ — просто текстовый, но аргументированный.
