# Миссия 036 — Битовый поток

> Уровень: `★★★☆☆` · Тема: битовые потоки, MSB/LSB-first

Битовый поток — способ уложить несколько чисел в один байт, не пролив ни бита. Плата учёта электроэнергии в «Гараже» шлёт данные именно так, и Дон уже месяц платит «не за то».
— Байт — это комната, — Зен показывает на экран. — А бит — квартирант. Умей селить их без шума.
Джез расселяет биты по комнатам, и счёт за электричество начинает совпадать с жизнью.

---

## Часть 1 — Чтение полей

Построй битовый ридер: чтение `n` бит (1 ≤ n ≤ 32) из файла, биты
идут **MSB-first** (старший бит байта первый). Прочитай последовательность
полей:

| Поле | Бит |
|------|-----|
| version | 3 |
| type | 5 |
| flags | 8 |
| length | 16 |

и выведи значения. Проверь на заголовке:

Файл `packet.bin` начинается с байтов `E1 A5 01 02`:

```
E1 = 1110 0001
A5 = 1010 0101
01 02 = 0000 0001 0000 0010
```

- version = `111` = 7
- type = `00001` = 1
- flags = `10100101` = 0xA5
- length = `0000 0001 0000 0010` = 0x0102

### Выход

```
VERSION=7 TYPE=1 FLAGS=0xA5 LENGTH=258
```

## Часть 2 — Запись

Обратный ридер-писатель: запиши те же поля в файл (MSB-first, поля
подряд без выравнивания) и проверь, что получились ровно байты
`E1 A5 01 02`. Выведи дамп записанных байт:

```
WRITTEN: E1 A5 01 02
```

## Подсказки

- Держи `bitpos` от 0 до 7 внутри текущего байта и курсор файла.
- Чтение: `byte >> (8 - n)` с поправкой на биты через границу байта —
  или читай байт за байтом и собирай в `acc <<= 8`.
- При записи не сбрасывай «хвост» бит — они дополнятся нулями в конце.
