# Миссия 067 — Текстовый квест

> Уровень: `★★★☆☆` · Тема: adventure, парсинг команд

Текстовый квест: комната, описание, команды. Джез пишет игру, в которой можно ходить словами, и
понимает, что весь мир — это текст, которому дали интерфейс.
— В каждой двери есть описание, — Зен улыбается впервые за вечер. — Вопрос — умеешь ли ты его
читать.
Джез читает описания и открывает двери, которые не открываются кнопками.

---

## Часть 1 — Движок комнат

Комнаты: `id`, `name`, `desc`, `exits` (направление → id комнаты),
`items` (список). Команды:

- `look` — описание комнаты;
- `go <dir>` — переход (n/s/e/w);
- `take <item>` — положить предмет в инвентарь (вывести `TAKEN`);
- `inv` — список инвентаря;
- `quit`.

Выведи описание стартовой комнаты и карту выходов:

```text
You are in the Neon Lounge.
Exits: n s e
Items: [keycard, ram]
```

## Часть 2 — Сценарий

Собери квест из файла `quest.txt` (формат сам придумай: например,
`# <id>` строки, `name:`, `desc:`, `exits: n=2,s=3`, `items:`).

Сюжет:

- комната 1 «Neon Lounge»;
- 2 «Back Alley» (ключ `keycard`);
- 3 «Server Room» (требует `keycard` при входе);
- 4 «Black Gate Terminal» — финал, `win`.

Пройди сценарий: `go s`, `go n`, `take keycard`, `go s`, `go e`, `win`.
Выведи итог:

```text
WIN: You jacked into the Black Gate terminal.
Moves: 6  Items: keycard
```

## Подсказки

- Парсер команд — разбивка по пробелам, первое слово — глагол.
- Двери с требованием предмета: exit может иметь условие `need:keycard`.
- Ввод для теста — из файла команд, по строке на команду.
