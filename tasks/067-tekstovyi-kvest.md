# Миссия 067 — Текстовый квест

> Уровень: `★★★☆☆` · Тема: adventure, парсинг команд

Текстовый квест: комната, описание, команды. Джез пишет игру, в которой можно ходить словами, и
понимает, что весь мир — это текст, которому дали интерфейс.
— В каждой двери есть описание, — Зен улыбается впервые за вечер. — Вопрос — умеешь ли ты его
читать.
Джез читает описания и открывает двери, которые не открываются кнопками.

---

## Данные

- `data/067/quest.txt` — комнаты: блок `# <id>`, затем строки
  `name:`, `desc:`, `exits: направление=id ...`, `items: ...`,
  опционально `need: предмет` (вход в комнату требует предмет);
- `data/067/commands.txt` — команды, по одной на строку.

## Часть 1 — Движок комнат

Разбери `quest.txt`. Выведи описание стартовой комнаты (id 1),
выходы (по алфавиту, через пробел) и предметы:

```text
You are in the Neon Lounge.
Exits: n s
Items: [ram]
```

## Часть 2 — Сценарий

Выполни команды из `commands.txt`:

- `go <dir>` — переход, если выход есть; если у целевой комнаты есть
  `need:` и предмета нет в инвентаре — перехода не происходит
  (команда считается выполненной);
- `take <item>` — положить предмет комнаты в инвентарь;
- `win` — финал.

Подсчитай `Moves` — число выполненных команд (включая `win`).
Выведи итог:

### Выход

```text
WIN: You jacked into the Black Gate terminal.
Moves: 7  Items: keycard
```

## Подсказки

- Парсер команд — разбивка по пробелам, первое слово — глагол.
- Направления: `n/s/e/w`; выходы в `quest.txt` могут идти в любом
  порядке — для Части 1 отсортируй.
- Предметы в инвентаре — в порядке взятия, через запятую с пробелом.
