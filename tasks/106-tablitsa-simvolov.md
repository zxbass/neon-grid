## Часть 1 — ELF-символы

ELF64, секция `.symtab` (формат из 082). Символ — 24 байта:

| Смещение | Поле |
| ---------- | ------ |
| 0 | name offset (u32, в strtab) |
| 8 | info (u8) |
| 12 | value (u64) |
| 20 | size (u64) |

Выведи функции (`info: type == 2`) с именем, адресом и размером:

```text
FUNCS:
  0x401000 init         size=64
  0x401040 validate_key size=512
  0x401240 decrypt      size=256

## Часть 2 — Портрет программы

Построй «портрет»: какие функции вызываются (ищи `call rel32` внутри
`.text` и сопоставь с таблицей функций). E8 xx xx xx xx — call с
относительным смещением: `target = next_ins + rel32`.

## Подсказки

- strtab — по `sh_link` секции `.symtab`.
- type символа: младшие 4 бита `info`.
- rel32 — signed 32-bit, big в little-endian; `target = (после опкода+смещения)`.
- Игнорируй вызовы за пределами известных функций (`(неизвестно)`).
