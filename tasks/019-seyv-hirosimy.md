# Миссия 019 — Сейв «Хирошимы»

> Уровень: `★★★☆☆` · Тема: игровые сейвы, данные персонажа

Сейв-файл с игрового автомата, найденный в кармане у «левого» курьера: профиль героя, инвентарь,
золото — и одна пометка, от которой у CROW глаза становятся квадратными.
— Кто-то накрутил опыт, — он щурится. — А ещё кто-то оставил в файле то, что не относится к игре.
Джез разбирает сейв по полям и находит строку, которая не должна была сюда попасть. Или должна была
— как раз для того, кто умеет читать.

---

## Часть 1 — Структура сейва

Сейв `save.bin`:

| Смещение | Поле |
| ---------- | ------ |
| 0 | версия (u16 LE) |
| 2 | имя героя (16 байт, до NUL) |
| 18 | HP (u16 LE) |
| 20 | MP (u16 LE) |
| 22 | золото (u32 LE) |
| 26 | уровень (u8) |
| 27 | XP (u32 LE) |
| 31 | число предметов (u8) |
| 32 | предметы: по 4 байта (id u16 LE, count u16 LE) |

Выведи:

```text
HERO=CROW_001 HP=100/100 MP=50/50 GOLD=9999 LVL=7 XP=32825
ITEMS: {3: 1, 77: 12, 5: 2, 1000: 1, 200: 9999}
```

## Часть 2 — Чит

«Хиросима» вписала себе читерские артефакты. Известно, что легитимных
предметов с id 1–99 и count ≤ 99. Найди «грязные» предметы (id > 99
или count > 99), выведи их и общую сумму золота. Также выведи XP: если
в значении XP установлен бит 15 — это сигнал читера (выведи
`CHEATER_FLAG`), а само значение печатай как есть (например, `0x8039`
печатается как `32825`).

### Выход

```text
DIRTY: {1000: 1, 200: 9999}
GOLD: 9999
XP: 32825 CHEATER_FLAG
```

## Подсказки

- Структуры фиксированной длины — читай по смещениям.
- Строки до NUL, max 16.
- Проверяй, что `число предметов ≤ 32`, иначе `SAVE_CORRUPT`.
