# Миссия 108 — Обфускатор «Туман»

> Уровень: `★★★★☆` · Тема: деобфускация, работа с кодом

Обфускатор-туман: код, в котором переменные переименованы в мусор, а логика спрятана за лишними
действиями. Джез учится видеть сквозь туман.
— Туман скрывает дорогу, — Прах смотрит на Джез. — Но не дорогу. Только твою уверенность.
Джез идёт сквозь туман.

## Часть 1 — Размотка констант

Исходник `fog.js` (или любой псевдокод) с выражениями вроде:

```js
var a = (0x1F + 0x20) * 3 - 0x3C + 0x7;

Вычисли все константные выражения (арифметика: + - * / ^ & | << >>),
замени на число. Выведи «чистый» вариант:

```js
var a = 95;

## Часть 2 — Имена и логика

- Переменные: `_0x1234` → читаемые `a, b, c...` в порядке появления.
- Строковые «константы» вида `"\x4e\x45\x4f\x4e"` → декодируй в `NEON`.
- Свёртка: `if (x) return true; else return false;` → `return x;`.

Дан обфусцированный фрагмент — выведи деобфусцированный:

```text
_0x1="\x4e\x45\x4f\x4e";
if (_0x1==="NEON"){return true;}else{return false;}
